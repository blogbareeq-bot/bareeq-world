# عالم بريق — الإصدار 3.1 — Astro 3.0

نسخة تحريرية واسعة من موقع **عالم بريق — نافذتك إلى المعرفة**، مبنية بـAstro ومهيأة للنشر المستمر على Cloudflare Pages من مستودع GitHub.

## ما يتضمنه الإصدار

- 8 مقالات حقيقية مستوردة من نسخة Blogger الاحتياطية، مع تواريخها وتصنيفاتها وصورها.
- تخطيط واسع يصل إلى 1460px للهيدر و1360px للمحتوى، مع عرض مريح لنص المقال.
- هيدر ذكي ثابت، وMega Menu يعرض أحدث ثلاث مقالات متاحة في كل قسم.
- قائمة جوال بأقسام قابلة للفتح تعرض أحدث المقالات دون مغادرة القائمة.
- صفحة رئيسية غير مكررة: Hero، قيم بريق، أحدث المقالات، كتاب الأسبوع، ثم CTA موحدة.
- نظام بطاقات متسق، ووضع فاتح افتراضي ووضع داكن اختياري مع حفظ التفضيل.
- صفحات المقالات والتصنيفات والوسوم والسلاسل والبحث و404.
- RSS وSitemap وبيانات SEO وOpen Graph وSchema.org.
- جدول محتويات ثابت في المقال مع تمييز القسم النشط وشريط تقدم قراءة دقيق.
- روابط تحويل دائمة من مسارات Blogger القديمة إلى المقالات الجديدة.
- منع فهرسة نطاق `pages.dev` عبر Cloudflare Middleware، مع إبقاء النطاق الرسمي قابلًا للفهرسة.
- لا توجد نماذج وهمية: التواصل عبر البريد المباشر، والنشرة البريدية معلنة على أنها «قريبًا».
- فحص آلي بعد البناء للروابط والموارد الداخلية داخل `dist`.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء والفحص

```bash
npm run build
```

ينشئ Astro الموقع داخل مجلد `dist`، ثم يشغّل `scripts/check-dist.mjs` للتأكد من عدم وجود مراجع داخلية مكسورة.

## إعداد Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: فارغ

## إضافة مقال

ضع ملف Markdown جديدًا داخل `src/content/posts/` وفق النموذج المشروح في `docs/إضافة-مقال.md`، وضع الصورة داخل `public/images/posts/`.
