# Bareeq World v4.21.4

إصدار مطابقة بصرية مبني على V4.21.3 المنشور. يثبت التصميم الأول بإطار 1440px وموجتي SVG مستقلتين للجوال وسطح المكتب، ويُبقي إصلاح شريط أحدث المقالات وإضافات كلود الجيدة منخفضة التشتيت.

## الجديد

- منع تمدد الهيدر على الشاشات الواسعة، وضبط لوحة الشعار والموجة وفق المرجع المعتمد.
- شريط جوال بعرض 288px عند 390px يكشف العناوين المتحركة بعد بطاقة «أحدث المقالات».
- شبكة أقسام بعرض 340px عند 390px و1280px كحد أقصى على سطح المكتب.
- تحقق فعلي في Chromium عند 320 / 360 / 390 / 768 / 1024 / 1440 / 1890 بلا overflow أو أخطاء متصفح.
- تطبيق التصميم الأول المرجعي باستخدام الشعار الأصلي: لوحة شعار بيضاء واضحة، موجة كحلية بلمسة فيروزية، شريط مقالات فاتح، وبطاقات أقسام منفصلة.
- نسخة جوال من الهوية نفسها، لا بديل أبيض مبسّط: منحنى أبيض للشعار فوق الخلفية الكحلية، أزرار البحث والقائمة في الجانب الداكن، وبطاقات أقسام بعمودين.
- إبقاء الوصول إلى الوضع الليلي ومحفوظات القراءة في درج الجوال والتذييل دون تشويه الهيدر المعتمد.
- استعادة كل تسجيل Sadaltager مكتمل من Production Cache قبل إرسال أي طلب جديد.
- محاولة **مقال واحد غير مكتمل كحد أقصى في كل بناء** عبر حصة Gemini المتاحة، مع إعطاء الأولوية لأقصر مقال لزيادة فرصة اكتماله.
- النشر الذري على مستوى المقال: لا يحل Sadaltager محل حامد/سيدر إلا بعد اكتمال جميع مقاطع المقال والـ manifest.
- عند استمرار 429 أو انتهاء ميزانية زمن البناء، ينجح البناء بالصوت البديل المعتمد ويؤجل المقال إلى نشر لاحق.
- عند غياب `GEMINI_API_KEY`، يرسل البناء صفر طلب توليد وينشر الأصوات الحالية.
- يبقى Google Cloud TTS المدفوع غير نشط ما دام `BAREEQ_CLOUD_TTS_ACTIVATE=0`، إلى ما بعد ربط CNTXT والموافقة على التفعيل.
- حماية روابط البريد من تحويل Cloudflare المسبب لمسار 404، مع اعتماد صندوق بريد النطاق الرسمي `info@bareeqworld.com` (حل محل `blogbareeq@gmail.com` بعد إنشاء الصندوق وتأكيده).
- تحديث سياسة الخصوصية لتوضيح محفوظات القراءة وموضع الاستماع المخزنين محليًا.
- مقالات توقيع ثابتة وصفحات سلاسل ذات وعد وترتيب، دون حقن طبقات إضافية داخل المقال.
- بحث يشمل مقتطف المتن، ومحفوظات `noindex`، وتحويل دائم لوسم الذكاء الاصطناعي القديم.
- تيكَر مقالات متصل يتحرك على الجوال، مع مجموعتين متماثلتين لمنع القفزة عند تكرار الحلقة.
- تنقيح العبارة التعريفية إلى «استمع إلى النص» في الرئيسية وصفحة «ابدأ من هنا».

## أوامر التحقق

- `npm ci --ignore-scripts`
- `npm run audit:v4214`
- `npm run plan:audio:gemini:pending` — يعرض خطة المقالات الـ11 بلا استدعاء API.
- `npm run test:audio:gemini:free` — يحاكي نجاح التوليد ثم 429 محليًا؛ لا يتصل بـ Gemini.
- `npm run build` — البناء والفحوص الكاملة.

## التشغيل الآمن

- يلزم وجود `GEMINI_API_KEY` كـ Production Secret في Cloudflare كي تبدأ المحاولة المجانية.
- `BAREEQ_GEMINI_FREE_ROLLOUT` مفعّل افتراضيًا؛ اضبطه على `0` فقط إذا أردت إيقاف المحاولات مؤقتًا.
- الحد المثبت هو مقال واحد: `BAREEQ_GEMINI_FREE_ARTICLES_PER_BUILD=1`.
- أبقِ `BAREEQ_CLOUD_TTS_ACTIVATE=0` قبل اكتمال CNTXT.
