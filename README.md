# عالم بريق — V4.3.0 Editorial Ready

نسخة إطلاق كاملة من **عالم بريق — نافذتك إلى المعرفة**، مبنية بـAstro ومهيأة للنشر من GitHub إلى Cloudflare Pages.

## الحكم

المصدر وناتج الإنتاج جاهزان للرفع. ينفذ `npm run build` تنظيف ناتج الإصدار السابق، وتوليد الصور المتجاوبة، وبناء الموقع، ثم يوقف العملية تلقائيًا عند وجود خلل في الروابط أو الوصول أو SEO أو الصور أو التباين أو الاستجابة أو التفاعلات الأساسية.

جاهزية المصدر والبناء لا تعني أن النطاق الرسمي يعمل تلقائيًا؛ يجب أن يعرض `bareeqworld.com` آخر نشر ناجح بحالة HTTP 200 قبل الإعلان العام.

## تحديث V4.3.0

- إضافة مقال «التضخم ببساطة: لماذا ترتفع الأسعار؟» إلى قسم «ببساطة…» بعد تحريره وتوثيقه وتوضيح الفرق بين مستوى الأسعار ومعدل التضخم والانكماش وتباطؤ التضخم.
- إضافة مقال «الوكلاء الأذكياء: من الإجابة إلى التنفيذ» إلى قسم «المستقبل الآن» بعد ضبط الفرق بين المحادثة وسير العمل والوكيل، وإضافة الصلاحيات والموافقة البشرية والحقن بالتعليمات والتقييم.
- رفع رصيد الموقع إلى **تسعة مقالات منشورة**، مع غلاف وصورة رمزية أصلية 16:9 لكل مقال جديد وأربعة مقاسات WebP للبطاقات.
- إبقاء بنية V4.2.0 وقراراتها المعمارية والتحريرية من دون تغيير غير لازم.

## أساس الإصدار V4.2.0

- توحيد تدقيقَي المحتوى وإصلاح هيكل الأقسام والسلاسل والوسوم والروابط السياقية.
- اعتماد سبعة مقالات منشورة؛ وإحالة مقال الترحيب المتقاعد ورابطه القديم تحويلًا دائمًا إلى «ابدأ من هنا».
- تصنيف «اللياقة بعد الأربعين» ضمن «بريق الكتب» و«كتب للحياة» بوصفه قراءة عملية في كتاب دون نافا.
- نقل نبذة الهوية إلى أعلى الرئيسية مباشرة بعد شريط الأقسام، وإزالتها من أسفل الصفحات.
- إضافة تعريف فريد لكل قسم، وصفحة «فريق بريق»، وسياسة أوضح للكتب والصور المساعدة والشفافية التجارية.
- احتساب زمن القراءة آليًا، وقصر الوسوم على اثنين للمقال، وعدم فهرسة الأرشيفات الرقيقة قبل ثلاثة مقالات.
- ترتيب المقالات المرتبطة بحسب السلسلة والوسوم والقسم بدل ملء المساحة بالأحدث فقط.

## أساس القياس في V4.1.1

- لا يُحمّل وسم Google ولا تُرسل بيانات قياس قبل موافقة الزائر الصريحة.
- خياران متكافئان وواضحان: «السماح بالقياس» و«متابعة دون قياس».
- زر دائم في التذييل لإعادة فتح إعدادات القياس وسحب الموافقة وحذف ملفات `_ga`.
- إشارات الإعلانات والتخصيص الإعلاني معطّلة، ومدة ملفات القياس محددة بـ13 شهرًا.
- تحديث سياسة الخصوصية وCSP واختبارات البناء لتغطية القبول والرفض والسحب.
- لا يظهر إشعار القياس ولا يعمل GA4 على نطاق المعاينة `pages.dev`.

## أساس الإصدار V4.1

- نظام صور تحريري مزدوج: غلاف كامل لصفحة المقال وصورة رمزية مستقلة 16:9 للبطاقات والقوائم والمشاركة الاجتماعية.
- سبع صور رمزية متناسقة مع هوية بريق، بلا نصوص مخبوزة أو قص عشوائي أو تكرار للعنوان.
- أربعة مقاسات WebP لكل صورة رمزية: 320 و640 و960 و1280 بكسل.
- ألوان الأقسام تعمل مع CSP الصارمة عبر فئات CSS ثابتة بدل الأنماط المضمّنة المحظورة.
- لا توجد أي سمة `style` مضمّنة في صفحات الإنتاج.
- انتقال ArrowDown إلى أول رابط في Mega Menu بعد اكتمال حركة الفتح، مع Escape وإعادة التركيز.
- أهداف لمس روابط التذييل 44px فأكثر.
- شريط تقدم قراءة أصلي وآمن باستخدام `<progress>` بدل تغيير نمط مضمّن.
- صور القائمة المنسدلة 16:9 ولا تُحمّل قبل فتح القائمة.
- روابط Blogger الثمانية القديمة تعمل؛ سبعة منها إلى المقالات الحالية وواحد إلى «ابدأ من هنا»، مع تحويل خلاصة Blogger إلى `/rss.xml`.
- تنظيف `dist/` قبل كل بناء لمنع بقاء ملفات إصدار قديم ذات أسماء مموهة.
- تحميل مسبق متجاوب لصورة البطل عبر `imagesrcset` و`imagesizes`.

## بنية الواجهة

- عرض تحريري ممتد حتى 1920px مع هامش آمن، وعرض قراءة مريح للمقال.
- رأس مستلهم من نسخة Blogger السابقة، وشريط أحدث المقالات، وخمسة أقسام فقط في الأعلى.
- لا يظهر «الكل» في شريط الأقسام، ولا يتكرر تنقل الأقسام في وسط الرئيسية أو التذييل.
- Mega Menu على سطح المكتب وAccordion داخل درج الجوال.
- تذييل جوال أحادي العمود وقابل للطي، وبريد إلكتروني باتجاه LTR وألوان نص موحدة.
- وضع داكن بتباين AA مختبر، وخطوط عربية ذاتية الاستضافة.

## البناء وبوابة الجودة

```bash
npm run build
```

الناتج النهائي في `dist/`. تشمل البوابة:

- الروابط والموارد والمسارات القديمة وخلاصة RSS.
- H1 وتسلسل العناوين وalt والأبعاد والمعرفات وARIA.
- العناوين والوصف وCanonical وOpen Graph والبيانات المنظمة وخريطة الموقع.
- منع الأنماط والسكريبتات التنفيذية المضمّنة المخالفة لـCSP.
- منع أكثر من صورة واحدة ذات `fetchpriority="high"`.
- التحقق من جميع صور البطاقات ونسبة 16:9 وعدد الملفات الرمزية الموافق لعدد المقالات المنشورة.
- التذييل عند 320 و390 و700 و768 و1024px، وأهداف لمس 44px.
- التباين في الوضعين الفاتح والداكن.
- القوائم ولوحة المفاتيح ودرج الجوال والثيم والشريط المتحرك وإشعار القياس والفهرس والبحث والتصفية.

## الرفع الصحيح — استبدال نظيف

1. فك ضغط الحزمة في مجلد مستقل.
2. افتح جذر مستودع GitHub الحالي واحتفظ بمجلد `.git` الخاص به.
3. انقل ملفات المشروع القديم إلى نسخة احتياطية، ثم انسخ **محتويات** حزمة V4.3.0 إلى جذر المستودع.
4. في GitHub Desktop تأكد من ظهور المقالين والصورتين المصدرّيتين الجديدتين إلى جانب الملفات المعدلة.
5. اكتب `Add inflation and AI agents articles (V4.3.0)` ثم اختر **Commit to main** و**Push origin**.
6. انتظر حالة **Success** في Cloudflare Pages.
7. افتح النطاق الرسمي والرئيسية والمقالات ومقالًا كاملًا في نافذة خاصة وعلى هاتف.

## فحص ما بعد النشر

```text
https://bareeqworld.com/
https://bareeqworld.com/articles/
https://bareeqworld.com/sitemap.xml
https://bareeqworld.com/robots.txt
```

على `pages.dev` يجب أن تظهر `X-Robots-Tag: noindex, nofollow, noarchive`. وعلى النطاق الرسمي يجب ألا تظهر ترويسة مانعة للفهرسة.
