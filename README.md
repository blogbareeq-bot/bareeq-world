# عالم بريق — Astro 2.0

نسخة كاملة من موقع **عالم بريق — نافذتك إلى المعرفة**، مبنية بـAstro ومهيأة للنشر على Cloudflare Pages من مستودع GitHub.

## ما يتضمنه الإصدار

- 8 مقالات حقيقية مستوردة من نسخة Blogger الاحتياطية، مع تواريخها وتصنيفاتها وصورها.
- 4 صفحات أصلية: عن بريق، الخصوصية، شروط الاستخدام وإخلاء المسؤولية، والتواصل.
- الشعار الرسمي المرفق محفوظ كما هو، دون إعادة رسم أو تغيير ألوان أو قص.
- صفحات المقالات والتصنيفات والوسوم والسلاسل والبحث و404.
- RSS وSitemap وبيانات SEO وOpen Graph وSchema.org.
- تصميم عربي RTL متجاوب من 320px حتى الشاشات الواسعة.
- وضع فاتح افتراضي ووضع داكن اختياري مع حفظ التفضيل.
- روابط تحويل دائمة من مسارات Blogger القديمة إلى المقالات الجديدة.
- منع فهرسة نطاق `pages.dev` عبر Cloudflare Middleware، مع إبقاء النطاق الرسمي قابلًا للفهرسة.
- لا توجد نماذج وهمية: التواصل عبر البريد المباشر، والنشرة البريدية معلنة على أنها «قريبًا».

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

ينشئ Astro الموقع داخل مجلد `dist`.

## إعداد Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: فارغ

## إضافة مقال

ضع ملف Markdown جديدًا داخل `src/content/posts/` وفق النموذج المشروح في `docs/إضافة-مقال.md`، وضع الصورة داخل `public/images/posts/`.

## ملاحظات

- ملف الشعار الأصلي محفوظ في `public/images/bareeq-logo-official.png`.
- النسخة الأصغر المستخدمة للعرض هي ملف رسمي موجود في النسخة الاحتياطية، ولم تُعدّل بصريًا.
- لا تتضمن الحزمة ملف Takeout الأصلي الكبير؛ بل تتضمن المحتوى المستخرج وبيان ترحيل في `docs/migration-manifest.json`.
