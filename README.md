# Bareeq World v4.21.0

حزمة المصدر الكاملة المستقرة لمدونة بريق، مبنية مباشرة على `bareeq-world-main(4).zip` بعد التحقق من سلامتها.

## الجديد

- تحميل manifest الصوت عند اختيار «استماع» فقط؛ لا تُضمّن بيانات المزوّد أو اسم الصوت في HTML الأولي.
- إخفاء بيانات اسم الصوت من الواجهة العامة مع إبقاء الوقت، الحالة، السرعة، الشفافية، وحفظ الموضع 30 يومًا.
- عند تغيير شريط التقدم، يبرز النص المقابل وتنتقل الصفحة إليه مباشرة على الجوال وسطح المكتب.
- تجهيز Cloud Text-to-Speech للنموذج `gemini-2.5-flash-tts` والصوت `Sadaltager` واللغة `ar-EG` وMP3 مباشر.
- بوابة تفعيل صريحة تبقي Cloud TTS متوقفًا قبل ربط CNTXT Billing؛ الوضع الافتراضي يرسل صفر طلب مدفوع.
- خطة ترحيل محصورة: 11 مقالًا معلّقًا + الاحتفاظ بمقالي Gemini المكتملين من Production Cache.
- تنبيه تراكمي اختياري لاستهلاك Azure قبل بلوغ الحد الشهري.
- الحفاظ على 13 مقالًا، التصميم المستقر، Analytics بموافقة المستخدم، والطبقات المعرفية التجريبية المؤجلة خارج الإصدار.

## أوامر التحقق

- `npm run audit:v4210`
- `npm run plan:audio:cloud:pending` — تخطيط فقط، بلا مفاتيح أو طلبات.
- `npm run build` — بناء وفحوص كاملة؛ يبقى Cloud TTS غير نشط ما دام `BAREEQ_CLOUD_TTS_ACTIVATE` لا يساوي `1`.

راجع `docs/دليل-الجاهزية-Cloud-TTS-v4.21.0.md` قبل أي تفعيل.
