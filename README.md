# Bareeq World v4.21.1

حزمة المصدر الكاملة لإصدار بريق V4.21.1، مبنية على V4.21.0 المستقر، وتجمع بين التصميم الأول المعتمد للهيدر والتوليد التدريجي الآمن للمقالات الصوتية المتبقية.

## الجديد

- تطبيق التصميم الأول للهيدر باستخدام الشعار الأصلي: لوحة شعار بيضاء واضحة، موجة كحلية بلمسة فيروزية، شريط مقالات فاتح، وشريط أقسام عائم.
- نسخة متجاوبة مضغوطة للتابلت، ونسخة جوال مبسطة بلا موجات أو تزاحم، مع بقاء البحث والوضع الليلي والقائمة ومحفوظات القراءة.
- استعادة كل تسجيل Sadaltager مكتمل من Production Cache قبل إرسال أي طلب جديد.
- محاولة **مقال واحد غير مكتمل كحد أقصى في كل بناء** عبر حصة Gemini المتاحة، مع إعطاء الأولوية لأقصر مقال لزيادة فرصة اكتماله.
- النشر الذري على مستوى المقال: لا يحل Sadaltager محل حامد/سيدر إلا بعد اكتمال جميع مقاطع المقال والـ manifest.
- عند استمرار 429 أو انتهاء ميزانية زمن البناء، ينجح البناء بالصوت البديل المعتمد ويؤجل المقال إلى نشر لاحق.
- عند غياب `GEMINI_API_KEY`، يرسل البناء صفر طلب توليد وينشر الأصوات الحالية.
- يبقى Google Cloud TTS المدفوع غير نشط ما دام `BAREEQ_CLOUD_TTS_ACTIVATE=0`، إلى ما بعد ربط CNTXT والموافقة على التفعيل.
- حماية روابط البريد من تحويل Cloudflare المسبب لمسار 404، مع إبقاء العنوان المؤكد `blogbareeq@gmail.com`.
- تحديث سياسة الخصوصية لتوضيح محفوظات القراءة وموضع الاستماع المخزنين محليًا.

## أوامر التحقق

- `npm ci --ignore-scripts`
- `npm run audit:v4211`
- `npm run plan:audio:gemini:pending` — يعرض خطة المقالات الـ11 بلا استدعاء API.
- `npm run test:audio:gemini:free` — يحاكي نجاح التوليد ثم 429 محليًا؛ لا يتصل بـ Gemini.
- `npm run build` — البناء والفحوص الكاملة.

## التشغيل الآمن

- يلزم وجود `GEMINI_API_KEY` كـ Production Secret في Cloudflare كي تبدأ المحاولة المجانية.
- `BAREEQ_GEMINI_FREE_ROLLOUT` مفعّل افتراضيًا؛ اضبطه على `0` فقط إذا أردت إيقاف المحاولات مؤقتًا.
- الحد المثبت هو مقال واحد: `BAREEQ_GEMINI_FREE_ARTICLES_PER_BUILD=1`.
- أبقِ `BAREEQ_CLOUD_TTS_ACTIVATE=0` قبل اكتمال CNTXT.
