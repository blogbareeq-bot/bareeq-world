# عالم بريق — V4.0.0 Launch Ready

نسخة إطلاق مستقرة من **عالم بريق — نافذتك إلى المعرفة**، مبنية بـAstro ومهيأة للنشر من GitHub إلى Cloudflare Pages.

## الحكم

المصدر وناتج الإنتاج جاهزان للرفع. ينفذ `npm run build` توليد الصور المتجاوبة، وبناء الموقع، ثم يوقف النشر تلقائيًا عند وجود خلل في الروابط أو الوصول أو SEO أو الصور أو التباين أو الاستجابة أو التفاعلات الأساسية.

لا يستطيع القالب نفسه إصلاح DNS النطاق الرسمي؛ يجب أن يعرض `bareeqworld.com` آخر نشر ناجح من لوحة Cloudflare قبل الإعلان العام.

## أهم ما في V4

- واجهة واسعة فعلًا: المحتوى التحريري الممتد يصل إلى 1920px مع هامش آمن، ويبقى نص المقال بعرض مريح.
- رأس مستلهم من نسخة Blogger السابقة، وشريط أحدث المقالات، وخمسة أقسام فقط في الأعلى.
- لا يتكرر تنقل الأقسام في وسط الصفحة أو التذييل، ولا يظهر خيار «الكل» في شريط الأقسام.
- Mega Menu مستقلة لكل قسم على سطح المكتب، وAccordion داخل درج الجوال، مع دعم النقر وArrowDown وEscape وإعادة التركيز.
- تذييل جوال أحادي العمود وقابل للطي، مع بريد LTR وألوان نص موحدة.
- أيقونات SVG موحدة بدل الرموز النصية التي يختلف شكلها بين الأنظمة.
- خطوط عربية ذاتية الاستضافة، دون طلبات Google Fonts.
- صور WebP متجاوبة بأحجام 320/640/960/1280، وصورة اجتماعية 1200×630 لكل مقال.
- صور Mega Menu لا تُحمّل قبل فتح القائمة.
- وضع داكن بتباين AA مختبر، وأهداف لمس أساسية لا تقل عن 44px.
- مقالات منقحة بمصادر مباشرة، وسياسة تحرير وتصحيح معلنة.
- وسوم وسلاسل ذات مقال واحد تحمل `noindex` ولا تدخل Sitemap.
- CSP وHSTS وسياسات أمان وكاش، و`pages.dev` يحمل `X-Robots-Tag: noindex` عبر Middleware.
- لا توجد صفحة إدارة أو نموذج اتصال أو نشرة وهمية في النشر العام.

```bash
npm ci

```

## البناء وبوابة الجودة

```bash
npm run build
```

الناتج في `dist/`. يشمل الفحص:

- الروابط والموارد والمسارات القديمة.
- H1 وتسلسل العناوين وalt والأبعاد والمعرفات وARIA.
- عناوين ووصف Canonical وOpen Graph وخريطة الموقع.
- منع أكثر من صورة واحدة `fetchpriority="high"`.
- منع سكربتات تنفيذية مضمّنة ومنع خطوط Google الخارجية.
- استجابة التذييل عند 320 و390 و700 و768 و1024px.
- تباين النصوص والأقسام في الوضعين الفاتح والداكن.
- فتح القوائم ولوحة المفاتيح ودرج الجوال والثيم وشريط الأخبار والفهرس والبحث والتصفية.

## إعداد Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: اتركه فارغًا
- Node.js: `22.16.0` أو إصدار Node 22 أحدث

## الرفع الصحيح — استبدال نظيف

هذه النقطة مهمة لأن النسخة السابقة أبقت ملفات قديمة مثل `/admin/` وصور شعارات ضخمة عند نسخ الحزمة فوق المستودع.

1. فك ضغط حزمة V4 في مجلد مستقل.
2. افتح مجلد مستودع GitHub الحالي، واحتفظ بمجلد `.git` المخفي فقط.
3. احذف ملفات المشروع القديمة، ثم انسخ **محتويات** مجلد V4 إلى جذر المستودع.
4. في GitHub Desktop تأكد من ظهور الحذف للملفات القديمة، والإضافة/التعديل لملفات V4.
5. اكتب وصفًا مثل `Release Bareeq V4.0.0` ثم اختر **Commit to main** و**Push origin**.
6. راقب Cloudflare Pages حتى تظهر حالة **Success** للبناء الجديد.
7. افحص `/admin/`؛ المطلوب أن يعيد 404، ثم افحص النطاق الرسمي و`pages.dev`.

## فحص ما بعد النشر

```text
https://bareeqworld.com/
https://bareeqworld.com/articles/
https://bareeqworld.com/sitemap.xml
https://bareeqworld.com/robots.txt
```

على `pages.dev` يجب أن تظهر ترويسة `X-Robots-Tag: noindex, nofollow, noarchive`. وعلى النطاق الرسمي يجب ألا تظهر هذه الترويسة.
