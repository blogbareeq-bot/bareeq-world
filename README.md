# عالم بريق — الإصدار 3.2.1 الجاهز للإطلاق

نسخة تحريرية واسعة من موقع **عالم بريق — نافذتك إلى المعرفة**، مبنية بـAstro ومهيأة للنشر المستمر على Cloudflare Pages من مستودع GitHub.

## ما يتضمنه الإصدار

- 8 مقالات حقيقية مستوردة من نسخة Blogger الاحتياطية، مع تواريخها وتصنيفاتها وصورها.
- تخطيط شبه كامل للنافذة يصل إلى 2048px للعناصر الممتدة و1920px للمحتوى الواسع، مع إبقاء نص المقال ضمن عمود قراءة مريح.
- رأس أبيض مدمج مستلهم من نسخة Blogger السابقة، يليه شريط «أحدث المقالات» وشريط الأقسام الأفقي.
- خمس قوائم منسدلة مستقلة للأقسام على سطح المكتب، تعرض أحدث ثلاث مقالات ورابط «تصفح القسم».
- قائمة جوال بأقسام قابلة للفتح، مع شريط علوي أفقي سريع للأقسام.
- صفحة رئيسية غير مكررة: Hero، قيم بريق، أحدث المقالات، كتاب الأسبوع، ثم CTA موحدة.
- لا يتكرر شريط الأقسام أو قائمة الأقسام داخل جسم الصفحة الرئيسية أو التذييل.
- أزيل خيار «الكل» غير الدال من شريط الأقسام؛ يبقى الوصول إلى جميع المقالات واضحًا في التنقل الرئيسي.
- وُحّد لون عنوان ونص وروابط قسم التواصل في التذييل لرفع الاتساق والوضوح.
- استُبعدت صفحة الإدارة التجريبية من النشر العام حتى لا يظهر مسار غير فعّال للزوار أو لمحركات البحث؛ حُفظ نموذجها داخل `docs/archive/`.
- نظام بطاقات متسق، ووضع فاتح افتراضي ووضع داكن اختياري مع حفظ التفضيل.
- صفحات المقالات والتصنيفات والوسوم والسلاسل والبحث و404.
- RSS وSitemap وبيانات SEO وOpen Graph وSchema.org.
- جدول محتويات ثابت في المقال مع تمييز القسم النشط وشريط تقدم قراءة دقيق.
- روابط تحويل دائمة من مسارات Blogger القديمة إلى المقالات الجديدة.
- منع فهرسة نطاق `pages.dev` عبر Cloudflare Middleware، مع إبقاء النطاق الرسمي قابلًا للفهرسة.
- لا توجد نماذج وهمية: التواصل عبر البريد المباشر، والنشرة البريدية معلنة على أنها «قريبًا».
- فحص آلي بعد البناء للروابط، والعناوين، والنصوص البديلة، ومعرّفات العناصر، وأزرار التفاعل، وعلاقات ARIA داخل `dist`.
- Astro 7.2.0 مع ملف قفل قابل لإعادة البناء، ونتيجة `npm audit` تساوي صفر ثغرات معروفة وقت إصدار الحزمة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء والفحص

```bash
npm run build
```

ينشئ Astro الموقع داخل مجلد `dist`، ثم يشغّل `scripts/check-dist.mjs` للتأكد من عدم وجود مراجع داخلية مكسورة.

## إعداد Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: فارغ
- Node.js version: `22.16.0` أو أحدث متوافق

## إضافة مقال

ضع ملف Markdown جديدًا داخل `src/content/posts/` وفق النموذج المشروح في `docs/إضافة-مقال.md`، وضع الصورة داخل `public/images/posts/`.

## ملاحظات

- صورة المشاركة الافتراضية هي `public/images/bareeq-social-card.webp` بأبعاد 1200×630 ووزن يقارب 10KB.
- الشعاران المرجعيان محفوظان داخل `docs/assets/` ولا يُنسخان إلى ناتج الإنتاج؛ الواجهة وبيانات المشاركة لا تحمّلهما.
- الهيدر والفوتر يستخدمان علامة متجهية نظيفة داخل المكوّن `Logo.astro` لتجنب الإطار الأبيض الكبير في صورة الشعار الأصلية.
- لا تتضمن الحزمة ملف Takeout الأصلي الكبير؛ بل تتضمن المحتوى المستخرج وبيان الترحيل.
