# دليل نشر ورجوع Bareeq V4.18.2

## الهدف

هذه نسخة **استبدال كامل** وليست Patch. لا تحتاج إلى تشغيل Node.js على جهاز المستخدم لتطبيق الملفات؛ Cloudflare هو الذي يشغّل البناء بعد رفع المشروع إلى GitHub.

## Cloudflare Production Variables

| النوع | المتغير | القيمة |
|---|---|---|
| Text | `BAREEQ_TTS_PROVIDER` | `gemini` |
| Secret | `GEMINI_API_KEY` | مفتاح Gemini Developer API |
| Text | `GEMINI_TTS_MIN_INTERVAL_MS` | `9000` |
| Text | `GEMINI_TTS_MAX_REQUEST_BYTES` | `2400` |
| Text | `BAREEQ_TTS_MAX_RETRIES` | `8` |
| Text | `BAREEQ_GEMINI_MAX_REQUESTS_PER_BUILD` | `80` |
| Text | `BAREEQ_GEMINI_SYNTHESIS_BUDGET_MS` | `780000` |
| Text | `BAREEQ_AUDIO_CACHE_ORIGIN` | `https://bareeqworld.com` |

يجب أن يبقى `GEMINI_API_KEY` Secret ولا يوضع داخل GitHub أو ملفات المشروع.

## تطبيق الحزمة الكاملة

1. من GitHub Desktop اختر `Repository → Show in Explorer`.
2. احتفظ بمجلد `.git` كما هو؛ فهو رابط المشروع المحلي بمستودع GitHub.
3. احذف **محتويات مشروع بريق الحالية فقط** باستثناء `.git`.
4. فك حزمة `bareeq-world-v4.18.2-full-replacement.zip` في مجلد مؤقت.
5. افتح المجلد الداخلي `bareeq-world` وانسخ **جميع محتوياته** إلى جذر المشروع بجانب `.git`.
6. افتح GitHub Desktop وراجع التغييرات، ثم Commit وPush.
7. يبدأ Cloudflare البناء تلقائيًا ويستعيد أي Sadaltager منشور سابقًا ثم يولّد الناقص فقط.

## GitHub Desktop

**Summary**

`feat: roll out resilient Sadaltager TTS across all articles`

**Description**

`Replace the one-article Gemini pilot with a full Sadaltager rollout for every published Bareeq article. Serialize synthesis at a 9-second minimum interval, add Retry-After aware retries and a Cloudflare-safe synthesis budget, cap new requests at 80 per build, preserve Cedar/Hamed fallback on persistent 429 limits, and resume only missing audio from the production cache.`

## ماذا يحدث إذا ظهر 429؟

- يحترم النظام مدة `Retry-After` التي يعيدها Google.
- يعيد المحاولة حتى 8 مرات.
- إذا استمر 429، لا يحذف الملفات المكتملة ولا يفشل النشر بسبب 429 وحده.
- يحتفظ المقال الحالي وما بعده مؤقتًا بـCedar/Hamed.
- عند إعادة النشر لاحقًا، تُستعاد مقالات Sadaltager المكتملة من الموقع الحي، ويُعاد طلب الناقص فقط.

## الرجوع الفوري

غيّر فقط:

`BAREEQ_TTS_PROVIDER=bundled`

ثم أعد النشر. هذا المسار يستخدم Cedar/Hamed المقفلين داخل المستودع ويفترض **0 طلب توليد**.
