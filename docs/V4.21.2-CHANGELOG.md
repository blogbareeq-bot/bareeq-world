# Bareeq V4.21.2 Changelog

إصدار منقّح يقفل التصميم الأول للهيدر، ويصلح شريط أحدث المقالات على الجوال، ويحافظ على إضافات كلود الجيدة من دون إدخال طبقات مزاحمة داخل المقال.

## المحفوظ من تحسينات كلود

- مقدمة الرئيسية الجديدة وصياغة «قراءات تحريرية» في صفحة «عن بريق».
- مقال توقيع لكل قسم وترتيب السلاسل ووعدها التحريري في صفحات الاكتشاف.
- مقتطف بحث من المحتوى، و`noindex` للمحفوظات، وإصلاح بنية `<main>` فيها.
- ثلاث خلاصات سريعة مصححة.
- توحيد وسم `الذكاء الاصطناعي` وتحويل 301 من المسار القديم.
- بوابات الإصدار 4.21.2 وتقارير الدمج والاختبار.

## المنقّح

- إزالة `bareeqAddition` وبطاقة `series-path` من داخل المقال مع إبقاء صفحات السلاسل نفسها.
- استبدال رمز المحفوظات التعبيري بأيقونة SVG متوافقة.
- حذف مولّد اللقطات الاصطناعية واستبدال اللقطات بصور Chromium حقيقية.
- تنظيف مجلدات استعادة الصوت المؤقتة ومنع تسربها إلى `dist`.

## الهيدر والشريط

- التصميم الأول فقط: موجة كحلية/فيروزية، لوحة شعار واضحة، شريط فاتح، وأقسام عائمة.
- حلقة مستمرة من مجموعتين متطابقتين؛ النسخة الثانية مخفية عن قارئ الشاشة.
- حركة JavaScript مقاسة على الجوال وحركة CSS على المقاسات الأكبر.
- زر إيقاف فعلي، ودعم `prefers-reduced-motion` مع تمرير يدوي.
- إعادة مزامنة بعد تغيير الاتجاه والمقاس وتحميل الخطوط، بلا overflow أفقي.

## التحقق

- `npm run build`: PASS — 56 صفحة.
- الصوت: PASS — 13/13 مقالًا، 61 جزءًا، 61 MP3، ولا طلب API خارجي.
- فحوص التوزيع والاستجابة والتباين والتفاعل: PASS.
- Chromium 140 عند 320 / 360 / 390 / 430 / 768 / 1024 / 1440: PASS بلا أخطاء أو overflow.
- حركة الجوال والإيقاف وتقليل الحركة: PASS.

## الثوابت

- 13 مقالًا منشورًا بلا تغيير في المتون.
- H1 الرئيسية: `عالم بريق — نافذتك إلى المعرفة`.
- Cloud TTS المدفوع غير مفعّل.
- لا إعلانات ولا نشرة ولا حسابات اجتماعية مضافة.
