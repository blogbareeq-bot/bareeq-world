- `node_modules/`

ثم نُفذ عليها:

1. `npm ci` — نجح، 250 حزمة.
2. `npm run voice:lab` — نجح.
3. `npm run build` — نجح.
4. `npm run voice:lab:check` بعد بناء الإنتاج — نجح.
5. اختبار كشف نتائج اصطناعية عبر `voice:lab:reveal` — نجح وحسب المتوسط والفوز وكتب النتيجة المكشوفة.

## حدود المرحلة الأولى

- لم تُستخدم مفاتيح ElevenLabs أو Google أو OpenAI أو Nabrah أو Munsit.
- لم تُجر مقارنة حقيقية بعد لوجود مرشح واحد فقط.

## بوابة المرحلة الثانية

الانتقال مسموح إلى بناء موصلات الخدمات وتوليد عينات الحالات الست فقط. لا يسمح بعد بإعادة توليد مكتبة المقالات الأحد عشر؛ ذلك يحدث بعد اعتماد الفائز، واختبار مقال كامل، وفحص النطق العكسي والجودة الصوتية.
