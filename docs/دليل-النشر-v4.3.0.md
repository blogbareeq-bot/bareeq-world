# دليل نشر عالم بريق V4.3.0

## قبل الرفع

- هذه حزمة مصدر Astro كاملة، وليست مجلد `dist` فقط.
- احتفظ بمجلد `.git` الموجود في مستودعك الحالي؛ لا تحذفه ولا تستبدله بمجلد من الحزمة.
- لا ترفع `node_modules/`. يستطيع Cloudflare إنشاء `dist/` من المصدر عبر `npm run build`.
- خذ نسخة احتياطية من الإصدار الموجود حاليًا خارج المستودع.

## الاستبدال النظيف عبر GitHub Desktop

1. فك ضغط `bareeq-world-astro-v4.3.0-editorial-ready.zip` في مجلد مستقل.
2. افتح المستودع الحالي في GitHub Desktop، ثم اختر **Repository > Show in Explorer**.
3. ادخل جذر المستودع الذي يحتوي على مجلد `.git` المخفي.
4. انقل محتويات المشروع القديمة إلى مجلد نسخة احتياطية خارج المستودع، مع إبقاء `.git` في مكانه.
5. انسخ **محتويات** الحزمة المفكوكة إلى جذر المستودع؛ يجب أن تكون `package.json` و`src/` و`public/` و`assets/` مباشرة في الجذر.
6. تأكد في GitHub Desktop من ظهور ملفي المقالين وصورتي المصدر الجديدتين والملفات المولدة والتوثيق.
7. اكتب Summary: `Add inflation and AI agents articles (V4.3.0)`.
8. اختر **Commit to main** ثم **Push origin**.

## إعداد Cloudflare Pages

لا تغيّر النطاق أو DNS أو قاعدة تحويل `www`. إعدادات البناء تبقى:

| الحقل | القيمة |
|---|---|
| Production branch | `main` |
| Framework preset | Astro، أو None |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | فارغ |
| Node.js | Node 22 حديث |

## صفحة التأكد من النشر

افتح **Cloudflare > Workers & Pages > bareeq-world > Deployments**. يجب أن يكون أحدث سجل:

- البيئة: **Production**.
- الفرع: `main`.
- الحالة: علامة خضراء **Success**.
- رسالة الـCommit: `Add inflation and AI agents articles (V4.3.0)`.

إذا ظهر Failed، افتح **Details** واقرأ أول خطأ فعلي في سجل البناء؛ لا تغيّر DNS.

## التحقق بعد النجاح

افتح الروابط التالية في نافذة خاصة:

```text
https://bareeqworld.com/
https://bareeqworld.com/articles/
https://bareeqworld.com/posts/altadakhom-explained-simply/
https://bareeqworld.com/posts/ai-agents-future-now/
https://bareeqworld.com/category/simply/
https://bareeqworld.com/category/future-now/
https://bareeqworld.com/sitemap.xml
https://bareeqworld.com/rss.xml
```

تحقق من الآتي:

1. يظهر مقال التضخم في «ببساطة…» ومقال الوكلاء في «المستقبل الآن».
2. الغلاف كامل وواضح في صفحة المقال، والصورة الرمزية 16:9 في البطاقات بلا قص مخل.
3. تعمل الفهارس والروابط والمصادر والقوائم في الجوال وسطح المكتب.
4. لا يظهر إشعار خطأ أو صفحة 404 لأي من المسارين الجديدين.
5. يظهر المقالان في `sitemap.xml` و`rss.xml`.
6. لا يعمل Google Analytics على `pages.dev`، ولا يبدأ على النطاق الرسمي قبل موافقة الزائر.

بعد التأكد، أعد إرسال `https://bareeqworld.com/sitemap.xml` في Search Console أو اترك Google يعيد قراءتها تلقائيًا؛ لا حاجة إلى طلب فهرسة متكرر للصفحة نفسها.

## الرجوع الآمن

إذا فشل النشر، استخدم آخر Deployment ناجح مؤقتًا أو أصلح خطأ البناء ثم أعد Push. لا تحذف النطاقات ولا تغيّر سجلات DNS ولا تستبدل `.git`.
