# تقرير اختبار بريق V4.8.0 — Enhanced Audio Reading

## نطاق التغيير

- تحسين نطق النسخة الصوتية بتشكيل/استبدالات انتقائية وSSML فقري.
- تظليل الكتلة النصية الحالية أثناء الصوت.
- تمرير ذكي للجوال.
- زر Stop مستقل.
- تنقل Tabs بلوحة المفاتيح.
- أهداف لمس 44px.

## الاختبارات المنفذة قبل التسليم

### المصدر والمنطق

- `node --check` نجح لـ `generate-audio.mjs`, `article.js`, وجميع فحوص الصوت الجديدة.
- `check-reading-modes.mjs`: ناجح لـ11 مقالًا.
- `check-audio-mobile.mjs`: ناجح.
- `check-audio-sync.mjs`: ناجح: **11 مقالًا، 30 جزءًا صوتيًا، 778 كتلة نصية متتبعة**.
- تحليل CSS عبر `tinycss2`: بلا أخطاء parsing.

### مطابقة النص بالمقال

تمت مقارنة خطة المزامنة مع HTML ناتج من CommonMark لكل المقالات الـ11؛ النتيجة **778/778 = 100%** من الكتل وجد لها هدف نصي مطابق بالترتيب.

### محاكاة Azure

تم تشغيل مولد الصوت كاملًا ضد خادم Azure محاكى:

- 11 manifest.
- 30 MP3.
- 778 مدخل مزامنة.
- التحقق من Manifest v2 وGenerator v5 وSync v1.
- التحقق من SSML `<p>`.
- التحقق من وصول تشكيلات النطق مثل `جُوزِف نَاي` و`أوبِن إيه آي` إلى طلب SSML.
- اجتاز `check-audio-dist.mjs` على ناتج صوتي محاكى.

### اختبارات متصفح فعلية

تم تشغيل Chromium عبر Playwright:

- شاشة جوال 390×844: تنقل ArrowLeft في RTL، انتقال التظليل بين فقرتين، بقاء التظليل عند Pause، ومسحه وإعادة الزمن عند Stop: **PASS**.
- شاشة ديسكتوب 1440×900: Home/End في Tabs وإدارة `aria-selected`: **PASS**.

## ما لم يمكن اختباره محليًا

- لم يُرسل طلب حقيقي إلى مورد Azure الخاص بالمستخدم لأن المفتاح Secret في Cloudflare ولا يجب نسخه خارجها.
- لم يُنفذ Astro production build كاملًا في هذه البيئة لأن registry الخاص بـnpm غير متاح شبكيًا هنا. لذلك يبقى Build Cloudflare بعد الـPush هو فحص التكامل النهائي مع Azure الحقيقي وAstro، كما في الإصدارات السابقة.

## بوابات البناء المضافة

أضيف `check-audio-sync.mjs` إلى `npm run build`. وسيفشل البناء إذا نقصت بيانات المزامنة أو اختلت نسب التوقيت أو فقدت كتلة صوتية ارتباطها بالنص.
