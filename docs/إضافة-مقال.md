# إضافة مقال إلى عالم بريق من GitHub

1. افتح `src/content/posts`.
2. اختر **Add file → Create new file**.
3. اكتب اسم الملف بالإنجليزية، مثال: `my-new-article.md`.
4. الصق نموذج المقال الموجود في README.
5. اضغط **Commit changes**.
6. سيعيد Cloudflare بناء الموقع تلقائيًا، وتظهر المقالة خلال دقائق.

لإخفاء مقال دون حذفه استخدم:

```yaml
draft: true
```
