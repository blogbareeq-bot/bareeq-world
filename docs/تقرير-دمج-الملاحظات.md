# تقرير دمج ملاحظات التصميم وإعادة الفحص — عالم بريق 3.0

## الخلاصة

تم دمج ملاحظات اقتراحات Claude مع إعادة الفحص والمراجعة البصرية للنسخة المنشورة، مع استبعاد المقترحات التي كانت ستعيد تكرار المحتوى أو تضيف وظائف غير مرتبطة بخدمة حقيقية.

## الملاحظات المنفذة

| المحور | القرار في الإصدار 3.0 |
|---|---|
| عرض الصفحة | 1460px للهيدر، 1360px للمحتوى، 760px لنص المقال |
| الأقسام | حذف شريط الأقسام المتكرر من الرئيسية، وإضافتها داخل Mega Menu والجوال |
| Mega Menu | آخر 3 مقالات متاحة لكل قسم، ووصف مختصر ورابط تصفح القسم |
| Hero | مقال رئيسي + مقالان جانبيان فقط |
| التكرار | منطق استبعاد يمنع ظهور المقال نفسه في Hero وأحدث المقالات وكتاب الأسبوع |
| أحدث المقالات | بطاقات متساوية بثلاثة أعمدة بدل بطاقة ضخمة غير متوازنة |
| سلاسل بريق | بقيت صفحة مستقلة، وأزيلت من الرئيسية حتى لا تكون نسخة ثانية من الأقسام |
| كتاب الأسبوع | يظهر من مقالات «بريق الكتب» دون تكراره في بقية الرئيسية |
| اختيارات بريق | تظهر فقط عند وجود 3 مقالات فريدة لم تظهر مسبقًا |
| الدعوات والنشرة | CTA واحدة قبل الفوتر، والنشرة «قريبًا» دون جمع بريد قبل تشغيل خدمة حقيقية |
| الاتصال | بريد مباشر وصفحة تواصل دون نموذج وهمي |
| الهيدر | ثابت وذكي، يصغر بعد التمرير، مع بحث ووضع داكن |
| الجوال | قائمة أقسام Accordion مع أحدث المقالات، ومنع تمرير الخلفية |
| صفحة المقال | TOC ثابت، تمييز العنوان النشط، شريط تقدم مبني على محتوى المقال |
| SEO | Canonical رسمي، Schema، OG، Sitemap، وnoindex ديناميكي لنطاق pages.dev |
| الجودة | فحص آلي للروابط والموارد الداخلية بعد كل Build |

## ما لم يُنفذ عمدًا

- نموذج اشتراك بريدي قبل اختيار خدمة وإعدادها فعليًا.
- نموذج اتصال يدّعي الإرسال دون Backend.
- روابط اجتماعية غير مؤكدة.
- قسم «الأكثر قراءة» دون وجود بيانات زيارات حقيقية.
- تكرار «اختيارات بريق» أو «سلاسل بريق» عند عدم توفر محتوى فريد كافٍ.

## نتيجة المراجعة المصدرية

- لا توجد نماذج `<form>` أو مسارات API وهمية.
- لا توجد روابط Blogger قديمة داخل المصدر؛ التحويلات القديمة محفوظة في `_redirects` فقط.
- جميع صور المقالات المشار إليها موجودة محليًا.
- أقواس CSS متطابقة.
- كتل JavaScript المضمنة اجتازت فحص Node.
- Frontmatter في ملفات Astro اجتاز فحص TypeScript النحوي.
