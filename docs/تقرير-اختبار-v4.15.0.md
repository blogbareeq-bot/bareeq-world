# تقرير اختبار Bareeq V4.15.0 — Dual OpenAI Voices

**التاريخ:** 13 أغسطس 2026  
**البيئة:** Node.js 24.14.0، npm 11.9.0، FFmpeg/ffprobe 6.1.1  
**النطاق:** مولّد الإنتاج، عقد OpenAI، الصوتان، المزامنة، المدة، الكاش، التكلفة، المشغّل، الجوال والتابلت، بناء Astro، وحزمة الرجوع.

## الحكم

**PASS — مصدر V4.15.0 وحزمة النشر جاهزان.**

نجح مسار الإنتاج كاملًا باستجابات OpenAI محاكية محليًا وملفات MP3 حقيقية صالحة للفحص، من دون اتصال مدفوع. لم تُولّد مكتبة Cedar/Marin الحقيقية في بيئة التسليم لعدم وجود `OPENAI_API_KEY`؛ يولّدها أول بناء ناجح في Cloudflare بعد إضافة المفتاح. جودة العينة الجديدة حُسمت من تجربة المستخدم السابقة، أما هذا التقرير فيثبت سلامة التكامل والبناء والواجهة.

## عقد OpenAI المثبت

| البند | النتيجة |
|---|---|
| Endpoint | `POST /v1/audio/speech` |
| النموذج | `gpt-4o-mini-tts-2025-12-15` |
| الصوتان | `cedar` و`marin` |
| الخرج | `response_format: mp3` |
| السرعة | `1` |
| المصادقة | `Authorization: Bearer …` في البناء فقط |
| تعليمات النبرة | عربية فصحى معرفية هادئة، بلا نبرة إعلانية |
| الإفصاح | ظاهر: الصوت مولّد بالذكاء الاصطناعي وليس صوتًا بشريًا |

تحقق خادم العقد المحلي من جسم كل طلب وترويسته قبل إعادة MP3، ورفض أي نموذج أو صوت أو صيغة أو تعليمات غير مطابقة.

## اختبار الإنتاج غير المدفوع

شُغّل `npm run test:release:mock`:

1. أنشأ MP3 محليًا صالحًا عند 24 kHz لاختبار محلل إطارات MPEG.
2. فتح خادمًا على `127.0.0.1` فقط.
3. استقبل **76 طلبًا مصادقًا**: 38 Cedar و38 Marin.
4. مرر كل استجابة في محلل المدة ثم كتبها ذريًا.
5. أنشأ manifest إصدار 3 لكل مقال.
6. بنى 50 صفحة Astro.
7. فحص 38 جزءًا و76 ملفًا وحجم كل ملف ومدته ومساره وصوته.
8. فحص عدم تسرب اسم متغير السر أو قيمته إلى `dist/`.

## خطة الرجوع

- **رجوع فوري:** إعادة نشر آخر Deployment ناجح لـV4.14.0 في Cloudflare Pages.
- **رجوع عبر Git:** إعادة Commit V4.14.0 ودفعه إلى `main`.
- **رجوع مع إبقاء واجهة V4.15.0:** ضبط `BAREEQ_TTS_PROVIDER=azure` وتوفير Azure Secret؛ الخطة المتحققة هي 11 مقالًا و60 طلبًا لصوتَي Hamed وZariyah.

لم يُجر توليد Azure ثنائي فعلي في هذا الاختبار لأنه غير مطلوب للإطلاق الجديد؛ موصل Azure المنشور وحواجزه بقيت من الإصدار السابق، وأضيفت خطة الصوتين وفحوص المصدر.

## ما يبقى بعد Push

التحقق الوحيد الذي لا يمكن تنفيذه من حزمة بلا مفتاح هو سماع **المكتبة الحقيقية المولّدة من OpenAI** على النطاق الرسمي. بعد نجاح Cloudflare، يُفحص مقال طويل على هاتف وتابلت بصوتَي Cedar وMarin، ثم تُعتمد حالة النشر. إذا أخفق التكامل أو لم تُرضِ النتيجة، يُستخدم Rollback إلى V4.14.0 فورًا.
