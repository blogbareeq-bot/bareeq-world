# تقرير اختبار Bareeq V4.17.2 — Gemini One-Article Pilot

**التاريخ:** 2026-08-16  
**النتيجة:** PASS — نطاق Gemini التجريبي ومزيج الصوت النهائي اجتازا الاختبارات المحلية غير المدفوعة.

## سبب الإصدار

أثبت نشرة V4.17.1 أن مفتاح Gemini وتحليل REST يعملان؛ نجح إنتاج مقال بصوت Sadaltager، ثم أوقفت حدود Gemini المجانية المحاولة عند رمز `429`. يخفض V4.17.2 الخطة من 70 طلبًا للمقالات الأحد عشر إلى 3 طلبات لمقال واحد.

## نطاق الإصدار

- مقال واحد بصوت `Sadaltager`: «عادات ثقافية مدهشة من حول العالم».
- 3 مقاطع Gemini متزامنة، إجمالي نص مصدري 2,914 حرفًا.
- عشرة مقالات بصوت Azure Hamed المدمج، وإجمالي 29 MP3 مقفلًا.
- تحليل REST الحالي: `steps → model_output → content → audio` مع `Api-Revision: 2026-05-20`.
- PCM أحادي 24 kHz / 16-bit إلى MP3 أحادي 48 kHz / 96 kbps.
- تظليل متزامن، شريط تقديم، سرعات، وحفظ موضع 30 يومًا.

## اختبار عقد Gemini المحلي

الأمر:

```bash
npm run test:audio:gemini:mock
```

النتيجة:

- **3/3** طلبات Sadaltager موثقة إلى خادم محلي، بلا اتصال بـGoogle وبلا تكلفة.
- التحقق من `x-goog-api-key`، وترويسة API، ومعرف النموذج، والصوت، وتعليمات الأداء، ووجود نص عربي.
- تحويل 3 استجابات PCM إلى 3 MP3 مع مدة وSHA-256 صحيحتين.
- فحص 11 مقالًا في مزيج الإنتاج: مقال Gemini وعشرة مقالات Hamed.
- فحص 32 ملف MP3 مؤقتًا ومتزامنًا، وعدم تسرب اسم المفتاح أو قيمته.
- استعادة حزمة Cedar/Hamed الأصلية بعد نهاية الاختبار.

## بوابات السلامة

- المعرف الوحيد لمقال Gemini مثبت صراحة في المولد.
- الخطة تعلن 3 طلبات لا 70، وتعلن المقالات العشرة الاحتياطية.
- فاحص الإنتاج يرفض Gemini خارج مقال التجربة.
- فاحص الإنتاج يشترط وجود ملفات Hamed للمقالات العشرة.
- حزمة الرجوع المقفلة بقيت بلا تغيير: Cedar لمقال واحد، و29 Hamed MP3 لعشرة مقالات، بإجمالي 93,092,832 بايت.
- لم تتغير الواجهة أو المقالات أو SEO أو CORS أو PWA.

## حدود الاختبار

لم يُستخدم مفتاح Gemini الحقيقي محليًا، لأنه محفوظ كـSecret في Cloudflare. يبقى النشر الناجح والاستماع البشري إلى المقال الكامل اختبار التكامل النهائي. إذا رفضت الحصة أيًا من الطلبات الثلاثة، يفشل النشر الجديد بأمان وتبقى آخر نسخة Production فعالة.

## قرار الإصدار

المصدر جاهز لتجربة مقال واحد بعد تجدد حصة Gemini. لا يُعمم Sadaltager على بقية المقالات إلا بإصدار مستقل وقرار صريح.
