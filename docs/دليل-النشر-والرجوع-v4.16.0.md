# دليل نشر ورجوع Bareeq V4.16.0

## ما الذي ستنشره؟

ينشر هذا الإصدار تسجيل Cedar المعتمد لمقال «عادات ثقافية من حول العالم» داخل الموقع، مع مدة 4:41 و21 علامة مزامنة وشريط تقديم/رجوع وحفظ موضع الاستماع 30 يومًا.

مجلد Voice Studio الذي ظهر لديك تحت:

```text
.bareeq_voice\published\bareeq-demo
```

هو مخرج صوتي وسيط، وليس جذر مستودع الموقع. استخدم **حزمة V4.16.0 النهائية كاملة** في جذر GitHub؛ لا تنسخ مجلد `bareeq-demo` وحده.

## إعداد Cloudflare Pages

في:

`Workers & Pages → bareeq-world → Settings → Variables and Secrets`

استخدم بيئة **Production**:

| المتغير | النوع | القيمة |
|---|---|---|
| `BAREEQ_TTS_PROVIDER` | Text | `openai` |
| `OPENAI_API_KEY` | Secret / Encrypt | مفتاح مشروع OpenAI بصلاحية Audio API |
| `OPENAI_TTS_BUILD_WARNING_USD` | Text | `8` |
| `OPENAI_TTS_BUILD_HARD_LIMIT_USD` | Text | `12` |
| `BAREEQ_AUDIO_CACHE_ORIGIN` | Text | `https://bareeqworld.com` |

لا تضف `BAREEQ_AUDIO_ALLOW_PARTIAL` إلى Cloudflare؛ هذا الخيار محصور ببناء التحقق المحلي، والإنتاج يجب أن يفشل بدل نشر مقالات ناقصة الصوت.

إعدادات البناء:

| الحقل | القيمة |
|---|---|
| Production branch | `main` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | فارغ |
| Node.js | Node 22 حديث، مثل `22.16.0` |

## ماذا يحدث في البناء؟

1. يتحقق من جميع إصلاحات المصدر والصوت والجوال والأمان.
2. يعيد إنشاء الصور المشتقة.
3. يستورد Cedar الحقيقي من الحزمة بلا API ولا تكلفة.
4. يحاول استعادة ملفات Cedar/Marin غير المتغيرة للمقالات العشرة الأخرى من النطاق الرسمي.
5. إذا تعذر الكاش، يولّد 72 ملفًا/طلبًا بتقدير محافظ 8.53 دولار.
6. يبني 50 صفحة ثم يشغّل فحوص الناتج؛ أي خطأ يوقف Deployment الجديد.

إذا كان نشر V4.15.0 الحالي سليمًا فالمتوقع أن تُستعاد المقالات العشرة بلا توليد جديد. وجود المفتاح المشفّر يبقى مهمًا لمسار الفشل الآمن عند فقد ملف من الكاش.

## الرفع عبر GitHub Desktop

1. فك ضغط حزمة V4.16.0 في مجلد مستقل.
2. افتح مجلد مستودع بريق الحالي، واحتفظ بمجلد `.git` الموجود فيه.
3. خذ نسخة احتياطية من الملفات الحالية.
4. انسخ **محتويات** مجلد V4.16.0 إلى جذر المستودع، لا المجلد الخارجي نفسه.
5. لا تنسخ `node_modules` أو `dist` إذا وُجدا محليًا؛ الحزمة النهائية لا تتضمنهما.
6. افتح GitHub Desktop وراجع التغييرات، ثم استخدم:

**Summary**

```text
feat: release v4.16.0 Cedar production audio pilot
```

**Description**

```text
Import the approved Cedar Studio release for the cultural-habits article as one synchronized 4:41 production track.
Add article-level seeking, exact 30-day local resume, single-voice UI handling, atomic immutable audio releases, and text-free synchronization metadata.
Preserve Cedar/Marin cache generation for other articles, Azure rollback, Arabic pronunciation QA, mobile category fixes, launch SEO/security fixes, and the selected navy-teal mobile homepage design.
Verified with two 50-page Astro builds, 72 authenticated mock OpenAI requests, 73 audited MP3 files, 778 synchronization blocks, and all release gates.
```

7. اختر **Commit to main** ثم **Push origin**.
8. انتظر **Success** في Cloudflare Pages؛ لا توقف البناء الأول ما دام يعمل.

## فحص ما بعد النشر

افتح مقال العادات الثقافية على هاتف وتابلت وسطح مكتب، ثم تحقق من:

1. ظهور تبويب «استماع» وزر «ابدأ الاستماع» من دون قائمة صوت فارغة.
2. ظهور الزمن الكامل 4:41.
3. عمل التشغيل والإيقاف المؤقت والمتابعة والإيقاف والسرعات وشريط التقديم.
4. انتقال التظليل بين 21 فقرة/عنوانًا/عنصر قائمة.
5. مغادرة المقال في منتصف الصوت ثم العودة وظهور «متابعة الاستماع» عند الثانية المحفوظة.
6. حذف الموضع عند الضغط على «إيقاف» أو بعد اكتمال التسجيل.
7. ظهور إفصاح الذكاء الاصطناعي وعبارة الحفظ لمدة 30 يومًا.
8. عدم وجود تمرير أفقي في الأقسام الخمسة على الجوال.
9. سلامة الرئيسية والمقالات والبحث و`/sitemap.xml` و`/robots.txt`.

## الرجوع السريع

أسرع مسار:

1. افتح **Cloudflare Pages → Deployments**.
2. اختر آخر نشر ناجح قبل V4.16.0.
3. استخدم **Rollback to this deployment**.

أو أعد Commit الإصدار السابق من Git. لأن Cloudflare يبدّل النشر كاملًا، لا يرى الزائر نصف إصدار صوتي.

## رجوع Azure داخل المصدر

إذا أردت الإبقاء على الواجهة مع Azure:

| المتغير | القيمة |
|---|---|
| `BAREEQ_TTS_PROVIDER` | `azure` |
| `AZURE_SPEECH_KEY` | Secret المورد الحالي |
| `AZURE_SPEECH_REGION` | `eastus` |
| `AZURE_SPEECH_ENDPOINT` | `https://eastus.api.cognitive.microsoft.com/` |

يستخدم هذا المسار Hamed وZariyah. يبقى Rollback إلى آخر Deployment ناجح أسرع إجراء عند الطوارئ.

## قاعدة الأمان

لا تضع أي مفتاح في GitHub أو ملف JavaScript أو وصف Commit. ولا تستخدم `BAREEQ_TTS_CONTRACT_TEST` أو `OPENAI_TTS_ENDPOINT` في Cloudflare؛ كلاهما محصور باختبار محلي يرفض العناوين غير المحلية.
