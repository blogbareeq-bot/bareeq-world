# دليل نشر عالم بريق V4.1.1

## طبيعة التحديث

يضيف هذا الإصدار Google Analytics 4 بنظام موافقة اختياري، ويحدّث سياسة الخصوصية وسياسة أمان المحتوى. لا يغيّر المقالات أو الصور أو الروابط أو إعدادات النطاق وSearch Console.

## الرفع عبر GitHub Desktop

1. فك ضغط `bareeq-world-v4.1.1-analytics-ready.zip` في مجلد مستقل.
2. من GitHub Desktop افتح **Repository > Show in Explorer**.
3. احتفظ بمجلد `.git` في جذر المستودع الحالي كما هو.
4. احتفظ بنسخة احتياطية من الملفات الحالية خارج المستودع.
5. انسخ **محتويات** مجلد `bareeq-world-astro-v4.1.1-analytics-ready` إلى جذر المستودع؛ لا تنسخ المجلد كطبقة إضافية.
6. وافق على استبدال الملفات، وتأكد أن GitHub Desktop يعرض الملفات المضافة والمعدلة والمحذوفة.
7. اكتب في Summary: `Add consent-first GA4 (V4.1.1)`.
8. اختر **Commit to main** ثم **Push origin**.

لا ترفع `node_modules/` أو `dist/`. ملف `.gitignore` يستبعدهما، وCloudflare يبني الناتج من المصدر.

## إعداد Cloudflare Pages

لا تغيّر الإعدادات الحالية:

| الحقل | القيمة |
|---|---|
| Production branch | `main` |
| Framework preset | Astro، أو None |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | فارغ |
| Node.js | `22.16.0` أو إصدار Node 22 أحدث |

## التحقق بعد النشر

1. افتح **Cloudflare > Workers & Pages > bareeq-world > Deployments** وتأكد أن آخر نشر حالته **Success**.
2. افتح `https://bareeqworld.com/` في نافذة خاصة جديدة.
3. يجب أن يظهر إشعار عربي فيه «متابعة دون قياس» و«السماح بالقياس».
4. اختر «السماح بالقياس»، ثم افتح صفحة أو مقالًا آخر.
5. في Google Analytics اضغط **Test installation** أو افتح **Realtime**؛ ينبغي ظهور زيارة خلال دقائق.
6. من تذييل الموقع اضغط «إعدادات القياس والخصوصية»، واختر «متابعة دون قياس» للتأكد من إمكانية سحب الموافقة.
7. افتح `/privacy/` وتأكد من ظهور قسم Google Analytics والقياس الاختياري.

نطاق `bareeq-world.pages.dev` مقصود أن يبقى بلا قياس وبلا إشعار موافقة، كما يبقى ممنوعًا من الفهرسة بترويسة `X-Robots-Tag`.

## ما لا يحتاج إلى إعادة

- لا تضف النطاقين المخصصين مرة أخرى.
- لا تعِد إنشاء تحويل `www`؛ القاعدة الحالية تبقى كما هي.
- لا تعِد إضافة موقع Search Console أو سجل إثبات الملكية.
- لا ترسل خريطة الموقع مرة أخرى؛ عنوانها لم يتغير.
- لا تطلب فهرسة الصفحات مجددًا بسبب هذا التحديث الصغير.

## ربط Search Console بعد وصول البيانات

بعد تأكد Google Analytics من استقبال الزيارة:

1. افتح **Admin** داخل Google Analytics.
2. ضمن **Product links** اختر **Search Console Links**.
3. اختر **Link** ثم خاصية `bareeqworld.com`.
4. اختر تدفّق الويب «عالم بريق – الموقع الرسمي».
5. راجع الإعدادات ثم اختر **Submit**.

## الرجوع الآمن

إذا فشل البناء، لا تغيّر DNS أو النطاق. استخدم آخر Deployment ناجح في Cloudflare أو أصلح خطأ البناء ثم أعد Push. وإذا ظهر خلل بعد نجاح النشر، نفّذ Rollback إلى V4.1.0 من صفحة Deployments.
