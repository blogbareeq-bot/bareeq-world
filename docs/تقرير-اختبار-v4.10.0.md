# تقرير اختبار Bareeq v4.10.0 — Mobile Navigation + Azure Cost Guard

## التغييرات
- إلغاء التمرير الأفقي لشريط الأقسام على الجوال واعتماد Flex-wrap Responsive يلتف تلقائيًا، بحيث يتمدد آخر صف بالتساوي بدل ترك فراغات غير متوازنة.
- السماح لأسماء الأقسام بالالتفاف بدل القص.
- تحسين شريط «أحدث المقالات» على الجوال باستخدام تسمية مختصرة وعنوان مختصر دلاليًا.
- إضافة حارس تكلفة Azure Speech أثناء البناء: تقدير أحرف التوليد الجديدة، تحذير، وحد أمان يوقف البناء عند تجاوز قيمة غير متوقعة.

## ملاحظة مهمة عن التكلفة
حارس البناء يقيس **هذا البناء فقط**، ولا يستطيع معرفة الاستهلاك الشهري الفعلي في حساب Azure دون ربط واجهة Azure Monitor/Billing. نظام بريق يعيد استخدام الصوت المنشور للمقالات غير المتغيرة، ولذلك لا يعيد توليدها بلا داعٍ.

## الاختبارات
- فحص JavaScript syntax.
- فحوص Middleware وReading Modes وAudio Mobile/Sync/Tablet.
- فحص مخصص يمنع رجوع `overflow-x:auto` لشريط أقسام الجوال.
- فحص وجود عناصر ticker المختصرة للجوال.
- فحص إعدادات Azure Speech cost guard في الكود و`.env.example`.

## المحافظة على تكلفة التوليد
لم يتم تغيير `GENERATOR_VERSION` لأن هذا الإصدار لا يغيّر النص الصوتي أو صيغة MP3؛ لذلك يمكن إعادة استخدام ملفات Azure المنشورة الحالية بدل إعادة توليد المكتبة كاملة لمجرد تحديث الواجهة.
