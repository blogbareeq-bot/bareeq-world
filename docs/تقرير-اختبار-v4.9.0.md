# تقرير اختبار بريق V4.9.0 — Fresh Home + Tablet Audio

## نطاق الإصدار
- إصلاح تشغيل القراءة الصوتية على الأجهزة اللوحية.
- تحسين تخطيط لوحة الاستماع على 681–1180px.
- تقوية تظليل الفقرة المقروءة.
- إصلاح هدف لمس زر شريط أحدث المقالات على الديسكتوب.
- معالجة CSP الخاص بـ Cloudflare Web Analytics beacon.
- تحويل مقال الواجهة الرئيسي إلى أحدث مقال منشور تلقائيًا.

## الإصلاح الوظيفي للتابلت
1. يضمّن Astro ملف `manifest.json` داخل صفحة المقال وقت البناء، فيصبح زر التشغيل جاهزًا دون انتظار fetch على الجهاز اللوحي.
2. `preload="none"` وعدم استدعاء `audio.load()` قبل أول تشغيل؛ `audio.play()` يُستدعى مباشرة من حدث نقر المستخدم.
3. مهلة بدء تشغيل 18 ثانية تعتمد حدث `playing` الحقيقي، وليس مجرد حالة `paused`.
4. عند فشل التشغيل أو منعه يظهر مسار احتياطي «استخدام مشغّل الجهاز» ويحوّل نفس عنصر HTMLAudio إلى controls أصلية.
5. fetch للشبكة باقٍ كاحتياط للتطوير فقط، بمهلة 9 ثوانٍ ومحاولتين.

## قيد بيئة الاختبار
تعذر تشغيل Astro production build محليًا لأن بيئة الاختبار لا تستطيع الوصول إلى npm registry (`EAI_AGAIN`). كما تمنع سياسة Chromium في البيئة فتح localhost/data/file، ولذلك لم يمكن إجراء محاكاة متصفح كاملة هنا. عوضًا عن ذلك، أضيفت فحوص بناء تلقائية إلى `npm run build`، وسيكون Cloudflare Deployment اختبار التكامل النهائي الحقيقي.
