# دليل نشر بريق V4.3.2

## محتوى الإصدار

- المشروع الكامل المتوافق مع Cloudflare Pages.
- 11 مقالًا منشورًا.
- مقال «أعط الصباح فرصة» وصوره الأصلية والمتجاوبة.
- إصلاح وصف سلسلة «كتب للحياة» في نتائج البحث.

## الاستبدال عبر GitHub Desktop

1. فك ضغط الحزمة في مجلد مستقل.
2. افتح مجلد المستودع الحالي، ولا تحذف مجلد `.git`.
3. احذف ملفات المشروع القديمة مع الإبقاء على `.git`، ثم انسخ **محتويات** مجلد الحزمة إلى جذر المستودع.
4. انتظر حتى يعرض GitHub Desktop جميع التغييرات.
5. اكتب في خانة Summary: `Release Bareeq V4.3.2 complete project`.
6. اختر `Commit to main` ثم `Push origin`.
7. في Cloudflare Pages انتظر ظهور علامة النجاح الخضراء للنشر الجديد.
