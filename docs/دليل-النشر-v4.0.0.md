# دليل نشر عالم بريق V4.0.0

## قبل البدء

- لا تنسخ V4 فوق ملفات الإصدار القديم؛ استخدم استبدالًا نظيفًا حتى تُحذف الملفات القديمة فعلًا.
- احتفظ بمجلد `.git` المخفي الخاص بالمستودع.
- تحذير LF/CRLF في GitHub Desktop معلوماتي ولا يمنع النشر ولا يغيّر عمل الموقع.

## الطريقة الموصى بها عبر GitHub Desktop

1. فك ضغط `bareeq-world-v4.0.0-launch-ready.zip` في مجلد مستقل.
2. افتح **Repository > Show in Explorer** من GitHub Desktop.
3. احتفظ بالمجلد المخفي `.git`، وانقل بقية ملفات المشروع القديم إلى نسخة احتياطية خارج المستودع.
4. انسخ **محتويات** مجلد `bareeq-world-astro-v4.0.0-launch-ready` إلى جذر المستودع؛ لا تنسخ المجلد كطبقة إضافية.
5. عد إلى GitHub Desktop وتأكد من ظهور ملفات محذوفة قديمة إلى جانب ملفات V4 المعدلة والمضافة.
6. اكتب في خانة Summary: `Release Bareeq V4.0.0`.
7. اختر **Commit to main** ثم **Push origin**.

## إعداد Cloudflare Pages

| الحقل | القيمة |
|---|---|
| Production branch | `main` |
| Framework preset | Astro، أو None مع الإعدادات التالية |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | فارغ |
| Node.js | `22.16.0` أو إصدار Node 22 أحدث |

وجود مجلد `functions/` في جذر المستودع مقصود؛ يستخدمه Cloudflare Pages لتطبيق منع الفهرسة على نطاق المعاينة.

## اعتماد النشر

1. افتح **Cloudflare Dashboard > Workers & Pages > bareeq-world > Deployments**.
2. انتظر حتى تظهر حالة **Success** لآخر Commit.
3. افتح النطاق الرسمي في نافذة خاصة لتجنب الكاش.
4. اختبر الروابط التالية:

```text
https://bareeqworld.com/
https://bareeqworld.com/articles/
https://bareeqworld.com/search/
https://bareeqworld.com/editorial-policy/
https://bareeqworld.com/sitemap.xml
https://bareeqworld.com/robots.txt
https://bareeqworld.com/admin/
```

المتوقع لـ`/admin/` هو 404؛ فهذا يؤكد عدم بقاء صفحة الإدارة القديمة.

## فحص الجوال الإلزامي

على هاتف بعرض قريب من 390px:

- لا يوجد تمرير أفقي للصفحة.
- الشعار والأزرار داخل عرض الشاشة.
- شريط الأقسام يبدأ بالأقسام الخمسة دون «الكل» ويمكن تمريره أفقيًا.
- زر القائمة يفتح درجًا واضحًا، وتفتح الأقسام كقوائم Accordion.
- التذييل عمود واحد؛ لا توجد كلمات مفككة أو أعمدة متداخلة.
- «روابط مهمة» و«تواصل معنا» يفتحان ويغلقان بصورة سليمة.
- البريد الإلكتروني يظهر في سطر مقروء واتجاهه من اليسار إلى اليمين.

## فحص الفهرسة والترويسات

نفّذ محليًا إن كان `curl` متاحًا:

```bash
curl -I https://bareeq-world.pages.dev/
curl -I https://bareeqworld.com/
```

- نطاق `pages.dev`: يجب أن يحتوي `X-Robots-Tag: noindex, nofollow, noarchive`.
- النطاق الرسمي: يجب ألا يحتوي ترويسة `X-Robots-Tag` مانعة للفهرسة.

## إذا ظهر الإصدار القديم

1. تأكد أن Deployment الأخير مرتبط بالـCommit الجديد.
2. نفّذ **Retry deployment** إذا فشل البناء.
3. امسح Cache من Cloudflare بعد نجاح البناء فقط.
4. افتح الموقع في نافذة خاصة.
5. راجع DNS وتأكد أن `bareeqworld.com` مرتبط بمشروع Pages الصحيح.

## الرجوع الآمن

لا تحذف النشر السابق من Cloudflare. إذا ظهر خلل غير متوقع بعد الرفع، استخدم **Rollback to this deployment** على آخر إصدار ناجح، ثم عالج السبب في فرع منفصل.
