## 1. النتيجة التنفيذية

انتقل النظام من نموذج:

```text
Visible article → selective speech-overrides → TTS provider
```

إلى:

```text
Visible article
→ deterministic segment extraction
→ reviewed contextual Speech Script
→ per-segment hashes/reviews
→ contextual ambiguity + transformation gate
→ reviewed Test Clip evidence
→ TTS provider
```

في حالة هذه المهمة:

- فُحصت المقالات المنشورة الخمسة عشر.
- أنشئ Speech Script مقطعي لكل مقال.
- اعتمد المقالان المرجعيان لغويًا ونطقيًا على مستوى النص.
- بقيت Test Clips في حالة `READY` فقط؛ لم تُولد ولم تُسمع، لذلك لا يوجد أي مقال في حالة `TTS Synthesis Allowed`.
- صُنفت المقالات: **A=2، B=5، C=8**.
- عدد المقالات المسموح لها بالوصول إلى مزود TTS: **0**.
- لم يتغير أي ملف مقال مرئي.
- لم يتغير أو يُستبدل أي ملف صوت منشور.
- لم تُحذف Manifests أو Gemini Checkpoints.
- لم تُستخدم مفاتيح Gemini/Azure/OpenAI/Google Cloud، ولم يُستدع مزود خارجي.

## 2. المشكلة التي عولجت

كان `optimizeForSpeech()` يطبق استبدالات محدودة ويحوّل النسب والمديات وينظف المسافات، من دون تحليل صرفي أو مراجعة سياقية كاملة. وكانت `check-arabic-speech.mjs` تتحقق من Body Hash ووجود عبارات منتقاة واحتواء الناتج على علامة تشكيل واحدة على الأقل.

لذلك كان نجاح الرسالة القديمة:

```text
Arabic Speech QA passed
```

يثبت سلامة بعض الاستبدالات، لكنه لا يثبت صحة النص المنطوق كاملًا، ولا يعني `Audio Ready`.

كذلك كانت دالة حذف المصادر تعتمد Regex يحتوي `\b` بعد نص عربي؛ وحدود الكلمات في JavaScript لا تعامل الأحرف العربية كما افترض التصميم. النتيجة أن عناوين المصادر العربية لم تُستبعد.

### دليل التسرب

خطة Legacy الحالية احتوت عناوين المصادر في **15 من 15 مقالًا**، ومنها:

- `المصادر`
- `المصادر والمراجع`
- `المصادر والتحقق`
- `المصادر والقراءة الإضافية`
- `مصادر للتوسع`

كما تأكد وجودها داخل Source Manifests لعشرة إصدارات Azure المجمعة، وفي Manifest شاشة اللمس المنشور.

## 3. البنية الجديدة

### 3.1 الاستخراج المقطعي

`script/speech-script-core.mjs` يستخرج:

- عنوان المقال.
- H2/H3/H4.
- الفقرات.
- عناصر القوائم.
- الاقتباسات.

ويستبعد ملحق المراجع باستخدام قائمة عناوين صريحة مطبّعة، لا Regex عام قد يحذف عنوانًا حقيقيًا مثل «مصادر الطاقة المتجددة».

### 3.2 المعرّفات والبصمات

لكل مقطع:

- `segmentId`: مشتق من النوع وبصمة النص، فيبقى ثابتًا ما بقي المقطع نفسه.
- `runtimeId`: ترتيب `b0001...` المستخدم للمزامنة المستقبلية.
- `sourceHash`: SHA-256 للنص المرئي لذلك المقطع.
- `sourceText`: لقفل المطابقة والمراجعة.
- `spokenText`: النص المعد للنطق.
- `transformations`: التحويلات المصرح بها فقط.
- `linguisticReview` و`pronunciationReview`.

ويحتوي الملف أيضًا على:

- `sourceSnapshotHash` للمقال وقت إنشاء الجرد.
- `sourceStructureHash` لكشف الإضافة والحذف وإعادة الترتيب.
- `scriptHash` لقفل كل النصوص المنطوقة والتحويلات.

إذا تغيرت فقرة واحدة، يصبح Segment القديم Stale ويظهر Segment جديد Missing، بينما تبقى مراجعات المقاطع الأخرى قابلة للتحقق. أما تغير الترتيب أو بنية الاستخراج فيظهر كـStructural Change ولا يمر بصمت.

### 3.3 التحويلات المسموحة

- `arabic-diacritization`
- `contextual-disambiguation`
- `number-expansion`
- `abbreviation-expansion`
- `foreign-name-pronunciation`
- `remove-duplicated-english`
- `punctuation-pause-normalization`
- `exclude-references`

أي نوع آخر يفشل. وبعد تطبيق التحويلات المعلنة، يقارن النظام النصين بعد نزع التشكيل وتطبيع الترقيم. إسقاط جملة أو تغيير كلمة دون تصريح يفشل.

### 3.4 الكلمات متعددة القراءات

أضيف Lexicon متعدد القراءات بدل قائمة «كلمات خطرة» أحادية، ويشمل حاليًا الفئات المرجعية المطلوبة مثل:

- `تعرف`: `تَعْرِفُ / تُعْرَفُ / تَتَعَرَّفُ`
- `تنتج`: `تُنْتِجُ / تَنْتُجُ`
- `ينتج`: `يَنْتُجُ / يُنْتِجُ`
- `تعدها`: `تَعُدُّهَا / تُعِدُّهَا`
- `سترد`: `سَتَرُدُّ / سَتَرِدُ`
- `تذكر`: `تَذْكُرُ / تَذَكَّرْ`
- `يحول`: `يُحَوِّلُ / يَحُولُ`
- `تولد`: المبني للمجهول والتوليد والتولد
- `تكون/تكوّن`، `ترتب`، `تغير`، `تحسب`، `تصدق`، `تصدر`، `تعلق`، `تشدد` وغيرها.

يدعم الفحص الواو والفاء المتصلتين مثل `وتذكر` و`وينتج`. وجود اللفظة من دون قراءة معتمدة يعني `REVIEW REQUIRED`، لا PASS.

### 3.5 المصطلحات الأجنبية

- تُفصل عن التشكيل العربي.
- حذف الإنجليزية المكررة يتطلب Transformation صريحًا.
- الاختصارات المهمة توسع بسياسة مستقلة.
- يمنع الفحص أي Token عربي صوتي مستقل يبدأ بسكون مثل `بْر...` أو `مْي...`.

### 3.6 Test Clip

أنشئت خطة لكل مقال، من 5–6 مقاطع خطرة غالبًا، بمدة متوقعة 30–60 ثانية.

- المقالان المرجعيان: `ready`.
- بقية المقالات: `draft-needs-speech-review`.
- `testClipPassed = false` للجميع.
- `fullSynthesisAllowed = false` للجميع.

مستقبلًا لا يقبل `Test Clip Passed` إلا إذا وُجد ملف دليل صوتي فعلي، وطابقت بصمته SHA-256، وسجل اسم المراجع وتاريخ المراجعة.

## 4. قفل الوصول إلى المزود

`generate-audio.mjs` يبني النص المستقبلي من Speech Script، ويضيف `speechScriptHash` إلى Provider Fingerprint والـManifest المستقبلي.

قبل أي Credential check أو Voice lookup أو Provider POST، تفحص `speech-synthesis-gate.mjs`:

1. اعتماد Speech Script كاملًا.
2. مطابقة Test Clip لنفس Script Hash.
3. `testClipPassed`.
4. وجود ملف Test Clip فعلي وبصمة مطابقة.
5. تسجيل مراجعة استماع.
6. `fullSynthesisAllowed`.

أي نقص ينتج:

```text
Speech synthesis blocked before provider access
No TTS provider request was sent
```

يوجد Escape Hatch واحد للاختبارات المحلية فقط، بقيمة إقرار طويلة، ولا يعمل إلا مع `BAREEQ_TTS_CONTRACT_TEST=1` وEndpoint على Loopback HTTP. لا يمكن استخدامه افتراضيًا أو مع مزود Production.

### توافق الصوت القديم

الأصوات المنشورة لم تُعد بناؤها. يحتفظ Provider `bundled` وCache-only validation بخطة Legacy للتحقق من الملفات الحالية فقط. أما أي **توليد جديد** فيستخدم Speech Script حصريًا ويخضع للبوابة الجديدة.

## 5. حالات الجودة

```text
Text Ready
→ Speech Script Ready
→ Linguistic Review Passed
→ Pronunciation Review Passed
→ Test Clip Ready
→ Test Clip Passed
→ TTS Synthesis Allowed
→ Audio Review Passed
→ Audio Ready
```

أعلى حالة تحققت في هذه المهمة للمقالين المرجعيين:

```text
Pronunciation Review Passed / Test Clip Ready
```

ولا يوجد `Test Clip Passed` أو `Audio Ready` جديد.

## 11. الاختبارات

### اختبارات البوابة الجديدة

- المقال غير المعتمد لا يصل إلى Provider POST.
- لا ينشأ MP3/WAV عند الرفض.
- تغير فقرة واحدة يبطلها وحدها ويحفظ مراجعات غيرها.
- تغير البنية/الترتيب يُكشف.
- صيغ المصادر الفعلية تُستبعد، و«مصادر الطاقة» لا تُحذف خطأ.
- العناوين والقوائم والاقتباسات تدخل الجرد.
- تغيير المعنى دون Transformation يفشل.
- Transformation مجهول يفشل.
- الغموض غير المحسوم يفشل.
- Token يبدأ بسكون يفشل.
- حذف الإنجليزية يحتاج تصريحًا صريحًا.
- Source Hash وScript Hash mismatch يفشلان.
- Gemini Prompt يستخدم النص المعتمد ويجعل الحركات authoritative.
- Audio/Test Clip status لا يمر بلا ملف دليل وبصمة ومراجع.
- Source Snapshot لكل المقالات مطابق.
