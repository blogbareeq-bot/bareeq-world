# دليل نشر عالم بريق V4.2.0

## قبل الرفع

- الحزمة مصدر Astro كامل، وليست مجلد `dist` فقط.
- احتفظ بمجلد `.git` الموجود في مستودعك الحالي؛ لا تستبدله ولا تنسخ `.git` من مكان آخر.
- لا ترفع `node_modules/` أو `dist/`؛ يبني Cloudflare الناتج من المصدر.
- احتفظ بنسخة احتياطية من V4.1.1 خارج المستودع قبل الاستبدال.

## الرفع عبر GitHub Desktop

1. فك ضغط `bareeq-world-v4.2.0-content-ready.zip` في مجلد مستقل.
2. افتح المستودع الحالي في GitHub Desktop، ثم **Repository > Show in Explorer**.
3. ادخل جذر المستودع الذي يحتوي مجلد `.git` المخفي.
4. انسخ **محتويات** مجلد `bareeq-world-astro-v4.2.0-content-ready` إلى الجذر؛ لا تنسخ المجلد نفسه كطبقة إضافية.
5. وافق على استبدال الملفات. يجب أن يعرض GitHub Desktop ملفات مضافة ومعدلة ومحذوفة، ومنها حذف مقال الترحيب وصورتيه المصدرية.
6. راجع أن `package.json` و`package-lock.json` و`src/` و`public/` و`docs/` تقع مباشرة في جذر المستودع.
7. اكتب Summary: `Content architecture and launch polish (V4.2.0)`.
8. اختر **Commit to main** ثم **Push origin**.

## إعداد Cloudflare Pages

لا تغيّر النطاق أو DNS أو تحويل `www`. تبقى إعدادات البناء:

| الحقل | القيمة |
|---|---|
| Production branch | `main` |
| Framework preset | Astro، أو None |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | فارغ |
| Node.js | Node 22 حديث |

## التحقق بعد النشر

1. تأكد من أن آخر Deployment يحمل حالة **Success**.
2. افتح `https://bareeqworld.com/` في نافذة خاصة.
3. تحقق من ظهور النبذة التعريفية مرة واحدة تحت شريط الأقسام، وعدم ظهورها قبل التذييل.
4. افتح `/category/bareeq-books/` وتأكد من وجود مقال «اللياقة بعد الأربعين» ومقدمة القسم.
5. افتح مقال اللياقة وتأكد من ظهور «بريق الكتب» في مسار الصفحة.
6. افتح رابط مقال الترحيب القديم؛ يجب أن ينتقل إلى `/start-here/` مع الحفاظ على النطاق الرسمي.
7. اختبر القائمة والقوائم المنسدلة والتذييل على هاتف حقيقي.
8. وافق على القياس في نافذة خاصة، ثم تحقق من Realtime في GA4؛ وبعدها جرّب سحب الموافقة من التذييل.
9. أعد إرسال `https://bareeqworld.com/sitemap.xml` في Search Console لأن بنية الروابط القابلة للفهرسة تغيرت.

## الرجوع الآمن

إذا فشل النشر، لا تغيّر DNS. افتح Cloudflare Pages واختر آخر Deployment ناجح، أو أصلح سجل البناء ثم أعد Push. النسخة السابقة وملفاتها تظل في النسخة الاحتياطية، بينما يحافظ التحويل 301 على رابط مقال الترحيب المتقاعد.
