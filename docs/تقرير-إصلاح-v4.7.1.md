# تقرير إصلاح بريق V4.7.1 — Azure Speech Resilient Audio

## سبب فشل V4.7.0
فشل بناء Cloudflare أثناء قراءة جسم استجابة صوتية من Azure بخطأ:
`TypeError: terminated` / `UND_ERR_SOCKET`.

## المعالجة
- تقليل `MAX_REQUEST_BYTES` من 12000 إلى 6000.
- اعتماد `audio-48khz-96kbitrate-mono-mp3` بدل 192kbps.
- إعادة محاولة أخطاء النقل: `UND_ERR_SOCKET`, `ECONNRESET`, `ETIMEDOUT`, وغيرها.
- إعادة المحاولة تغطي تنزيل جسم MP3 بعد استجابة HTTP 200، وليس طلب HTTP فقط.
- تطبيق الحماية نفسها على استعادة ملفات الصوت من النسخة المنشورة.
- الإبقاء على التهدئة بين طلبات Azure بما يلائم F0.
