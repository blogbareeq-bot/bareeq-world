# تقرير مخاطر الأصوات الحالية — دون إعادة توليد

**التاريخ:** 25 أغسطس 2026  
**الغرض:** تحديد أولوية الاستماع أو إعادة التوليد مستقبلًا، من دون إنشاء أو حذف أو استبدال أي صوت في هذه المهمة.

## منهج الحكم

هذا التقرير لا يدعي أنه استمع إلى كل التسجيلات. يعتمد على:

1. Speech Plans والنص الذي استُخدم عند إنتاج الصوت القديم.
2. Manifests وSource Manifests المتاحة محليًا.
3. عدد مواضع الغموض والمصطلحات الأجنبية في الجرد الجديد.
4. مدى تغطية `speech-review` التاريخي.
5. الملاحظات المسموعة المعروفة في المقالين المرجعيين.

### معنى التصنيفات

- **لا توجد مؤشرات قوية:** لا يوجد دليل بنيوي مهم؛ لا يعني أن الصوت مثالي.
- **Listening Review موجّه:** لا يوجد دليل كافٍ لإعادة كاملة قبل سماع مواضع الخطر.
- **أسباب قوية لإعادة التوليد مستقبلًا:** يوجد تسرب مراجع مؤكد، أو مخاطرة لغوية كبيرة جدًا، أو خطأ معروف. لا ينفذ التوليد قبل Speech Script + Test Clip.

## النتيجة

- لا توجد مؤشرات قوية: **0**.
- يحتاج Listening Review موجّه: **1**.
- توجد أسباب قوية لإعادة التوليد مستقبلًا: **14**.

سبب عدم وضع أي مقال في الفئة الأولى هو أن خطة Legacy الحالية سرّبت المراجع في 15/15 مقالًا. لكن ملف Studio المحلي لمقال العادات لا يعرض دليلًا مباشرًا على أن تسجيله الفعلي قرأ المصادر، ولذلك أبقيناه في المراجعة الموجهة بدل قرار الإعادة.

## ترتيب المراجعة المقترح

1. شاشة اللمس والجوازات: لأن Speech Scripts الجديدة جاهزة لـTest Clip.
2. المحتوى الصحي: اللياقة بعد الأربعين.
3. المقالات C الأطول أو كثيرة المصطلحات: زميل الذكاء الاصطناعي، الوكلاء، اللغة، الأقمار، أعط الصباح.
4. بقية تسجيلات Azure ذات المصادر المؤكدة.
5. مقال العادات: Listening Review فقط أولًا.

## قيد مهم

وجود سبب قوي لإعادة التوليد لا يسمح بتوليده الآن. يجب أن يمر بالترتيب:

```text
Speech Script Passed
→ Test Clip Generated
→ Test Clip Listening Review Passed
→ Full Synthesis Allowed
→ Full Audio Listening Review Passed
→ Atomic Replacement
```
