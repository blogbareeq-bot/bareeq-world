## 6. Classification rules

### ASR_CONTEXT_INSTABILITY
Use only if audio/PCM outside the guard band is unchanged while ASR changes in that unchanged region.

### SPLICE_EFFECT
Use when new acoustic or recognition errors are localized to the splice/transition guard band.

### TRUE_TTS_REGRESSION
Use when the replacement region itself contains a new spoken/acoustic regression attributable to the new synthesis.

### REPRESENTATION_MISMATCH
Use when the audio is acceptable and the remaining disagreement is a proven textual representation issue covered by narrow adjudication evidence.

### MIXED_CAUSE
Use when more than one independently supported cause is present.

### INSUFFICIENT_EVIDENCE
Use only after the retained artifact and available caches/checkpoints have been inspected and still cannot establish causality.
