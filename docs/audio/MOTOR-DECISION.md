## Technical decision rule

For each sample:

`delta = Gemini baseline errors - Chirp Dual-ASR consensus errors`

Technical pilot passes only when all conditions hold:

- Technical QA passes for all three generated files.
- No sample regresses by more than one error (`delta < -1` is forbidden).
- Any regression of three or more errors is an immediate failure.
- Fewer than two samples regress.
- Sum of the three deltas is positive.
- At least two samples improve (`delta > 0`).

A technical pass is **not** an engine activation. It only advances to the voice/splice review below.
