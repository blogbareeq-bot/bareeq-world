# عالم بريق 3.0 — النسخة التحريرية الواسعة

هذه النسخة توحّد ملاحظات تقرير Claude، إعادة الفحص، والمراجعة البصرية للصفحة التجريبية.

## التغييرات الرئيسية

- توسيع تخطيط الصفحة: 1460px للهيدر و1360px للمحتوى، مع إبقاء نص المقال عند 760px.
- إعادة بناء الهيدر ليصبح ثابتًا وذكيًا، ويصغر بعد التمرير.
- إضافة Mega Menu للأقسام الخمسة، يعرض آخر ثلاث مقالات متاحة في كل قسم أثناء بناء Astro.
- تحويل الأقسام في قائمة الجوال إلى Accordion يعرض أحدث المقالات وروابط الأقسام.
- حذف شريط الأقسام المتكرر من الصفحة الرئيسية.
- إعادة بناء Hero: مقال رئيسي ومقالان جانبيان فقط.
- منع تكرار المقالات بين Hero وأحدث المقالات وكتاب الأسبوع.
- جعل بطاقات أحدث المقالات متساوية بدل البطاقة الكبيرة غير المتوازنة.
- إبقاء «سلاسل بريق» في صفحتها المستقلة وإزالتها من الرئيسية حتى لا تتكرر الأقسام.
- إضافة «كتاب الأسبوع» ككتلة تحريرية مستقلة، بشرط وجود مقال من «بريق الكتب».
- دمج الدعوات المتكررة والنشرة في CTA واحدة قبل الفوتر، دون نموذج بريد وهمي.
- تطوير الفوتر إلى أربعة أعمدة مع بريد تواصل حقيقي ودون روابط اجتماعية وهمية.
- استبدال صورة الشعار الكبيرة في الهيدر بشعار متجهي مدمج ونظيف مستوحى من رمز بريق، مع إبقاء الشعار الرسمي لصورة المشاركة.
- تحسين جدول محتويات المقال وتحديد العنوان النشط أثناء القراءة.
- تحسين شريط تقدم القراءة ليقيس محتوى المقال نفسه.
- تحسين التباين، التركيز بلوحة المفاتيح، دعم الحركة المخفضة، والجوال 320px.
- تحسين robots.txt على نطاق pages.dev عبر Middleware: منع كامل للفهرسة على النسخة التجريبية.
- إضافة فحص آلي بعد البناء لجميع الروابط والموارد الداخلية في مجلد dist.

## قرارات تحريرية

- لم يُضف نموذج اشتراك قبل ربط خدمة بريدية فعلية.
- لم يُضف نموذج اتصال وهمي؛ التواصل عبر البريد وصفحة الاتصال.
- قسم «اختيارات بريق» يظهر آليًا فقط عند توفر ثلاثة مقالات فريدة لم تظهر في الأقسام السابقة.
- «الأكثر قراءة» غير مفعّل قبل توفر بيانات قراءة حقيقية.
