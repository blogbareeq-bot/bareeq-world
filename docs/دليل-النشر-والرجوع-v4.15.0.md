# دليل نشر ورجوع Bareeq V4.15.0

## النتيجة

هذا الإصدار ينقل القراءة الصوتية المنشورة إلى OpenAI `gpt-4o-mini-tts-2025-12-15`، ويعرض خيارين داخل كل مقال:

- **سيدر (Cedar)** — الاختيار الافتراضي.
- **مارين (Marin)** — الاختيار الثاني.

يُحفظ اختيار القارئ بين المقالات والجلسات، ويُحفظ موضع كل مقال لمدة 30 يومًا على الجهاز نفسه. لا يُرسل مفتاح OpenAI إلى المتصفح؛ يستخدمه بناء Cloudflare فقط، ثم تُقدَّم ملفات MP3 من نطاق بريق.

## الإجراء الوحيد المطلوب قبل الرفع

في Cloudflare Pages افتح:

`Workers & Pages → bareeq-world → Settings → Variables and Secrets`

أضف للبيئة **Production**:

| المتغير | النوع | القيمة |
|---|---|---|
| `BAREEQ_TTS_PROVIDER` | Text | `openai` |
| `OPENAI_API_KEY` | Secret / Encrypt | مفتاح مشروع OpenAI |
| `OPENAI_TTS_BUILD_WARNING_USD` | Text | `8` |
| `OPENAI_TTS_BUILD_HARD_LIMIT_USD` | Text | `12` |
| `BAREEQ_AUDIO_CACHE_ORIGIN` | Text | `https://bareeqworld.com` |

لا تضع قيمة `OPENAI_API_KEY` في GitHub أو ملف `.env` مرفوع أو وصف Commit.

## الرفع عبر GitHub Desktop

1. احتفظ بنسخة ZIP من V4.14.0 كما هي.
2. فك حزمة V4.15.0 في مجلد مستقل.
3. داخل مستودع بريق الحالي احتفظ بمجلد `.git`، واستبدل ملفات المشروع بمحتويات الحزمة الجديدة.
4. افتح GitHub Desktop وراجع التغييرات.
5. استخدم بيانات Commit التالية:

**Summary**

```text
feat: release v4.15.0 dual OpenAI article voices
```

**Description**

```text
Publish Cedar and Marin as two selectable OpenAI TTS voices for all articles.
Persist the selected voice and per-article listening position on the device.
Keep paragraph synchronization, tablet fallback, mobile category fixes, and Arabic pronunciation QA.
Add exact MP3 duration metadata, AI-voice disclosure, production cache reuse, cost guards, and Azure Hamed/Zariyah rollback mode.
Verified with 76 mocked OpenAI speech requests, two complete builds, 50 pages, 38 synchronized parts, 778 tracked blocks, and all release audits.
```

6. اختر **Commit to main** ثم **Push origin**.
7. راقب Cloudflare Pages حتى تظهر حالة **Success**.

## ماذا يحدث في أول بناء؟

- تُخطط 38 قطعة صوتية لكل صوت، أي 76 طلب توليد و76 ملف MP3.
- التقدير المحافظ الحالي لأول توليد كامل: **8.85 دولار**.
- يظهر تنبيه عند 8 دولارات.
- يوقف البناء نفسه قبل الاتصال إذا تجاوز التقدير 12 دولارًا.
- إذا غاب المفتاح، يفشل النشر الجديد وتبقى النسخة السابقة على الموقع.

مدة البناء الأولى تعتمد على سرعة OpenAI وحدود حساب المشروع. لا تغلق أو تعِد تشغيل النشر ما دام Cloudflare يعرض أن البناء مستمر.

## البناء اللاحق والكاش

بعد نجاح V4.15.0 على النطاق الرسمي، يعيد البناء اللاحق تنزيل الصوت المنشور إذا تطابقت بصمة:

- نص المقال المنطوق.
- قاموس النطق ومراجعة العربية.
- النموذج والصوتان وتعليمات النبرة.
- بيانات المزامنة وصيغة الإخراج.

إذا لم يتغير شيء، تكون الخطة **0 طلب جديد و0 دولار تقديريًا**. إذا تغير مقال واحد، يُعاد توليد صوتيه فقط.

## فحص ما بعد النشر

افتح مقالًا طويلًا على هاتف وتابلت وسطح مكتب، ثم تحقق من:

1. ظهور Cedar وMarin في قائمة «الصوت».
2. بدء Cedar افتراضيًا.
3. انتقال المصدر إلى Marin عند اختياره.
4. استمرار تظليل الفقرة والتمرير الذكي.
5. ظهور الزمن الكلي للمقال بدل رقم الجزء.
6. بقاء الصوت المختار بعد فتح مقال آخر.
7. ظهور «متابعة الاستماع» بعد مغادرة المقال والعودة إليه.
8. ظهور إفصاح أن الصوت مولّد بالذكاء الاصطناعي.
9. عدم وجود تمرير أفقي في شريط الأقسام على الجوال.

## الرجوع السريع إلى V4.14.0

أسرع رجوع لا يحتاج توليدًا:

1. افتح **Cloudflare Pages → Deployments**.
2. اختر آخر نشر ناجح قبل V4.15.0.
3. استخدم **Rollback to this deployment**.

أو أعد نشر Commit V4.14.0 من Git/GitHub ثم ادفعه إلى `main`. كلا المسارين يعيدان الصوت السابق وواجهة الإصدار السابق.

## الرجوع داخل V4.15.0 إلى Azure

إذا أردت الاحتفاظ بواجهة الصوتين الجديدة مع Azure:

| المتغير | القيمة |
|---|---|
| `BAREEQ_TTS_PROVIDER` | `azure` |
| `AZURE_SPEECH_KEY` | Secret المورد الحالي |
| `AZURE_SPEECH_REGION` | `eastus` |
| `AZURE_SPEECH_ENDPOINT` | `https://eastus.api.cognitive.microsoft.com/` |

ينشر هذا الوضع **Hamed** و**Zariyah** مع حاجز Azure القديم. لأنه مخطط ثنائي جديد، يحتاج المفتاح لتوليد الصوتين أول مرة؛ لذلك يبقى Rollback إلى نشر V4.14.0 أسرع في حالة الطوارئ.

## قاعدة الأمان

لا تستخدم `BAREEQ_TTS_CONTRACT_TEST` أو `OPENAI_TTS_ENDPOINT` في Cloudflare. هذان محصوران باختبار محلي صريح، ولا يقبل الكود إلا عنوانًا محليًا عند تشغيلهما.
