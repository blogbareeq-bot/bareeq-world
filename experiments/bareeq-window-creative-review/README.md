# بريق — نموذج «سطور · صدى · نافذة»

هذه تجربة مستقلة لمراجعة وتطوير تجربة قراءة المقال في مشروع بريق.

## التسميات المعتمدة
- **سطور** — النص الكامل للمقال.
- **صدى** — الاستماع إلى المقال مع النص.
- **نافذة** — التجربة البصرية التفاعلية.

## الهدف
تحسين «نافذة» إبداعيًا مع الحفاظ على روح بريق: فخامة، رسمية، بساطة، وهوية عربية تحريرية معاصرة. هذه ليست نسخة نهائية للنشر، بل مساحة تجريب قبل التعميم.

## القرار التحريري
تم إلغاء «الخلاصة» كطريقة قراءة مستقلة. لا تعاد إضافتها كخيار رابع.

## مكونات التجربة
- `preview.html` — النموذج التفاعلي المستقل.
- `ArticleReadingModes.tsx` — واجهة طرق القراءة.
- `RELEASE_SPEC_WINDOW.md` — وثيقة الإصدار والمبادئ.
- `CLAUDE_PROMPT.md` — الأمر الموجه إلى Claude لإنتاج 3 نماذج بديلة لـ«نافذة».
